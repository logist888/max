# report — сборка отчёта

## Шаги

1. **Уточнить вход:** тема и охват; **поток** (1 или 2 — оба в одних метриках
   нельзя); аудитория (персонаж Ольга/Инесса/Андрей/Валерий или команда);
   формат (документ/таблица/презентация/PDF); адресат (клиент HNW / команда).

2. **Собрать материал:** `vault/00-index/MOC.md` → отобрать заметки по меткам,
   потоку, сущностям (`rg` по `vault/`). Данных мало — отметить пробел, не выдумывать.

3. **Структура** — из `vault/_templates/report.md`. Для клиентского отчёта
   профориентации: четыре голоса (психология / обучение / карьера / синтез) и
   разделы скрининга; принцип «сначала неудобная находка». Эталон формата —
   по образцу Игоря, когда он его даст.

4. **Жёсткие правила на выходе:**
   - один поток; метрики другого не подмешивать;
   - выводы на гипотезе скрининга — с явной оговоркой о невалидированности;
   - команда обезличена: направление + ответственный в скобках, без имён;
   - каждый премиум-факт — источник + дата + ссылка; без источника убрать или пометить;
   - тесты — рабочие переименования, не BFAS/RIASEC.

5. **Черновик** — `vault/40-reports/<id>.md`.

6. **Экспорт PDF:** `python3 scripts/pdf_ru.py vault/40-reports/<id>.md <out>.pdf "Заголовок"`.
   Убедиться, что PDF создан (кириллица, DejaVu).

7. **Доставка** в Drive (папка MainExperts) — по подтверждению Игоря.

8. **Закрой проверкой:** к какому из двух потоков и к какой из трёх целей относится отчёт.
