# boot — загрузка системы MainExperts

Выполни по шагам, ничего не выдумывая.

1. Прочитай канон и протокол:
   - `CLAUDE.md` (поведение, жёсткие правила), `SYSTEM.md` (устройство);
   - `docs/01-strategy.md` … `docs/07-principles-open-questions.md` — кураторский
     канон знаний;
   - `vault/00-index/MOC.md` и `vault/00-index/tags.md` — карта и словарь меток.
   `docs/private/` без явной причины не открывать (поток-1, конфиденциально).
   `memory/memory.md` (дословный снимок Диска) и `reference/` — по требованию.
2. Поставь зависимости: `bash scripts/setup.sh` (среда эфемерна).
3. Сверься с Drive: в папке MainExperts (id `1K_2OdWBh9xnLcBy7S6VXpq97PxSsDNr9`)
   проверь, нет ли версии памяти новее снимка; расхождения назвать вслух.
4. Проверь рабочее хранилище: заметки в `vault/10-sources`, `vault/20-notes`,
   `vault/30-entities`; есть ли `status: требует-проверки`.
5. Доложи коротко: стадия, два потока, узкое место, блокеры, расхождения. Без воды.
6. Жди материал. Файл → `ingest` или `report`; не очевидно — спроси.

Жёсткие правила (`CLAUDE.md`) держать всегда: два потока раздельно; гипотеза
скрининга не валидирована; переименование тестов; источник+дата+ссылка;
обезличивание команды на выходе.
