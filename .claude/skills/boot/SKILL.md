# boot — загрузка системы MainExperts

Выполни по шагам, ничего не выдумывая.

1. Прочитай: `CLAUDE.md`, `SYSTEM.md`, `memory/memory.md`, `vault/00-index/MOC.md`,
   `vault/00-index/tags.md`. Это основа контекста.
2. Поставь зависимости: `bash scripts/setup.sh` (среда эфемерна).
3. Сверься с Drive: найди в папке MainExperts (id `1K_2OdWBh9xnLcBy7S6VXpq97PxSsDNr9`)
   свежайший `memory_v*.md`. Если он новее снимка `memory/memory.md` — обнови снимок
   и назови расхождения вслух.
4. Проверь хранилище: число заметок в `vault/10-sources`, `vault/20-notes`,
   `vault/30-entities`; дата `MOC.md`; заметки со `status: требует-проверки`.
5. Доложи коротко: загруженное, состояние хранилища, расхождения, блокеры. Без воды.
6. Жди материал. Файл → `ingest` или `report`; не очевидно — спроси.

Жёсткие правила (`CLAUDE.md`) держать всегда: два потока раздельно; гипотеза
скрининга не валидирована; переименование тестов; источник+дата+ссылка;
обезличивание команды на выходе.
