# publish — тройная выгрузка артефакта

По умолчанию готовый артефакт уходит в три места разом. Перед выгрузкой — жёсткие
правила из `CLAUDE.md`: поток-1 и `docs/private/` в общий git и общий Drive не выносить
(такой артефакт сам конфиденциален).

## Шаги
1. **Git.** Положить файл в репозиторий (рабочие артефакты — `vault/40-reports/`),
   `git add -A`, убедиться, что `docs/private/` не в индексе, коммит, `git push -u origin <ветка>`.
2. **Чат.** Отдать файл через `SendUserFile`.
3. **Drive.** Залить в папку MainExperts (id `1K_2OdWBh9xnLcBy7S6VXpq97PxSsDNr9`):
   - текст (md/html) — `create_file` с `textContent`, точным `contentMimeType`
     (`text/html`, `text/markdown`) и `disableConversionToGoogleType: true`;
   - бинарь (PDF/xlsx) — `base64Content`;
   - имя с версией: `…(vX.Y).html`.
4. **Сверка целости.** Сравнить `fileSize` из ответа Drive с локальным размером
   (`wc -c`). Не совпало — копия битая: попросить удалить её (MCP не удаляет) и перезалить.
5. **Правило двух версий.** В папке держать ровно две версии (текущая + предыдущая).
   Указать, какой старый файл удалить вручную (MCP не удаляет и не переименовывает).
6. **Доклад:** ссылки на три выгрузки и что удалить на Диске.

Большие файлы: точная копия — в git (дёшево, история); Drive — опубликованная копия,
её выгрузка тяжёлая (контент инлайнится), потому размер сверять всегда.
