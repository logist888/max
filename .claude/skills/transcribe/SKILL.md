# transcribe — расшифровка записи по голосам

Локальный пайплайн на процессоре: запись не уходит наружу. Код и подробности —
`scripts/transcribe/README.md`.

## Шаги

1. **Окружение.** `scripts/transcribe/setup.sh` — ffmpeg, пакеты, модели диаризации.
   Контейнер эфемерный, после пересоздания ставится заново.
2. **Файл.** С Google Drive качать напрямую, не через MCP: `download_file_content`
   отдаёт base64 в контекст и на записи в сотни мегабайт непригоден.
   ```bash
   ID=<file_id>
   curl -sSL -c /tmp/cj "https://drive.google.com/uc?export=download&id=$ID" -o /tmp/p.html
   # взять из формы uuid и confirm, затем:
   curl -sSL "https://drive.usercontent.google.com/download?id=$ID&export=download&confirm=t&uuid=<uuid>" -o raw/<имя>.webm
   ```
   Сверить размер с метаданными Drive. Сырьё — в `raw/` (вне git).
3. **Прогон.** Заранее посмотреть длительность (`ffprobe`) и предупредить о времени:
   считается примерно как длительность записи.
   ```bash
   nohup python3 scripts/transcribe/diarize_asr.py raw/<файл> -o transcripts/ > /tmp/tr.log 2>&1 &
   ```
   Число участников, если известно, задавать ключом `-s N` — точность разметки выше.
4. **Имена.** Прогон даёт «Говорящий 1…N». Прочитать первые минуты транскрипта:
   представления и обращения по имени обычно дают соответствие. Составить
   `transcripts/<файл>.names.json` и пересобрать с `--names` (секунды, работает из кеша).
   Атрибуция, выведенная из контекста, — предположение; помечать как таковое,
   не выдавать за факт.
5. **Выдача.** `.md` — в чат и в git; `.txt` — под дальнейший разбор моделью.
   Тяжёлые `.wav` и кеш `transcripts/.work/` в git не идут.
6. **Дальше по системе.** Транскрипт встречи — материал для хранилища: предложить
   `ingest` (заметки в `vault/`) и, если встреча меняет факты уровня канона, правку
   `docs/`. Публикация артефакта — скилл `publish`.

## Что говорить о качестве

Не выдавать транскрипт за протокол. При выдаче назвать прямо: перекрывающаяся речь
приписывается одному голосу, короткие вставки липнут к соседу, термины и суммы
распознаются с ошибками. Цифры, цитаты и имена, идущие в материалы клиентам,
сверяются с записью.
