## 2. Как слои v4 связаны с картой

[факт] В v4 три оси разведены: Q — класс задач (22 ветви), J — состояние образовательного маршрута (9), P — услуга-кандидат (26). Это частичный порядок, не одна последовательность.

[допущение] Колонка стикера услуги — первая группа её ветки Q. Услуги одной ветки стоят в одной колонке стопкой: у Q11 их четыре (P11, P23, P25, P26), у Q15 две (P15, P24). Состояние J стоит в колонке первой из своих веток (J01 → Q01, J03 → Q04, J05 → Q11, J07 → Q13, J09 → Q22), поэтому колонка показывает только вход в состояние.

## 4. Критический разбор: что v4 не доказывает для MainExperts

1. [вывод] Комплект описывает услуги исходящей мобильности по 14 образовательным системам (поступление, допуск, заявка, признание, виза). Профориентация подростков 10–18 лет, ядро Потока 2, покрывается рядами P01, P19, P21 (состояния J01 и J09). По P01 D3 у 7 запросов из 4 562 (0,15 %); большая часть сигнала — D1 и D2. Центральная гипотеза проекта (скрининг оцифровывает страх родителя, и тот покупает диагностику) этим комплектом не проверена и остаётся ставкой.
2. [факт] Покупок нет (D5–D6 без данных), цен услуг в комплекте нет. Цены в концепте портала — демонстрационные значения, придуманные при сборке (`docs/28`, раздел 31). Использовать их как основу решения нельзя.
3. [вывод] Противоречие с каноном GTM. `docs/11` (ревизия 08.07) исходит из полной автоматизации пакета: узкое место снято, ограничение — спрос. Услуги R01–R04 в v4 держатся на минутах эксперта (экспертный разбор, проверка спорных правил), их стоимость входит в порог окупаемости v4: вклад заказа за вычетом возвратов, комиссий и времени эксперта. Какая из двух моделей верна для платного уровня Профиля 360, не решено.
4. [допущение] Рынки v4 (США, Великобритания, Германия и т. д.) не совпадают с целевыми СНГ и MENA. Россия и ОАЭ есть, Казахстан и Узбекистан нет. Первый пилот v4 (США, английский язык) вне стратегического фокуса проекта; для рынков проекта его можно брать как механику, не как доказательство спроса.
5. [вывод] Слой v4 делит «бесплатное» и «платное» по правилу: бесплатный результат сразу, платное по триггеру. Это снимает часть спорного пункта `docs/24` (что открыто в бесплатном скрининге, что платно), но число бесплатных функций, которые закроют задачу без покупки, остаётся главным риском: v4 называет его первой причиной возможного провала.
6. [пробел] Имена партнёров, условия агентских выплат, порядок проверки полномочий партнёра, сроки хранения документов, условия возврата, налоги — не заданы. Сколько минут эксперта уходит на заказ — не измерено.

## 6. Что осталось неизменным и что по-прежнему отсутствует

- [пробел] Эмоций, мотивов, каналов и персонажей нет; ряд эмоций не создавался. Для CJM клиента нужны данные custdev (`docs/03`, `docs/27`).
- [пробел] Частоты запросов по ветвям Q нет: онтология не агрегирует объёмы, а в v4 они даны только как число уникальных формулировок и оценки поставщика по отдельным строкам; складывать их по языкам и рынкам нельзя.
- Карта очень широкая: 14 766 × 13 873 пикселей. Читать удобнее в `.html` с масштабом или по этапам.
