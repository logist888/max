# 24. Локализация портала: план, ограничения, решения

Актуально на 13.11.2026. Версия 1. Дополнение к `docs/22` (ТЗ на SEO-страницы) и `docs/23` (мета-данные). Решение владельца (13.11.2026): локализация, сначала английская версия, затем русская; страницы строятся сразу на двух языках. Образцы: `docs/html/seo-samples/en/` и `ru/`.

Разметка: Ф — факт из входов; П — предложение (значение по умолчанию); пробел — данных нет. Коды: `Л-номер` — требование, `ОЛ-номер` — открытое решение.

## 1. Что меняется относительно ТЗ

| Было | Стало | Причина |
|---|---|---|
| `docs/22` R-9.10: языки первого выпуска ru и en, основной ru | Основной английский, русский следом; оба на старте с равной структурой | решение 13.11.2026 |
| Интерфейс портала на русском (`themes/kuda/lang/ru.json`, Ф по ДС) | Строки интерфейса выносятся в ключи с двумя языками | страницы строятся сразу на двух языках |
| Олимпиады только на ru (Ф, ДС §5D) | Для en раздел скрыт (нет данных), не переводится автоматически | у олимпиад нет английского наполнения |
| Список профессий «берётся по рынку языка страницы» (Ф, ДС §5B) | Язык и рынок разводятся (Л-2) | иначе английская страница автоматически получит чужой рынок |

## 2. Схема адресов и языков

**Л-1. Адрес.** Префикс языка у всех публичных страниц: `/en/...`, `/ru/...`. Корень `/` — выбор языка без контента и без индексации; первый заход перенаправляется по `Accept-Language` и cookie, роботу отдаётся страница выбора со ссылками. `x-default` = `/en/...`. Ист.: П.

**Л-2. Три независимые оси.** Язык страницы (интерфейс и тексты), рынок пользователя (валюта, «откуда», перелёт) и страна обучения. Рынок не выводится из языка. Индексируемая страница показывает цену в валюте страны обучения (R-11.4 `docs/22`); рублёвая и иная персонализация подгружается отдельно и не входит в кэш. Ист.: ДС (cookie `market`, `currency`), П.

**Л-3. Слаги.** Один слаг на сущность для всех языков: латиница, транслитерация или английское название плюс идентификатор (`seo-platform/01-model-ia.md` В3). Тогда пара страниц отличается только префиксом: `/en/universities/{slug}` и `/ru/universities/{slug}`. Смена слага — 301 на всех языках одновременно. Ист.: ПС.

**Л-4. Сегменты фильтров в адресах T43.** Коды, общие для языков (`de`, `it`, `bachelor`, `en`, `free`, `2027`). Сегмент языка обучения `en` не путать с префиксом языка страницы `/en/`: допускается `/en/p/de/it/bachelor/en/free` (П; при споре — код языка обучения `eng`). Ист.: `docs/22` R-4.3.1.

**Л-5. hreflang.** Для каждой пары страниц взаимный `hreflang` (`en`, `ru`) и `x-default`; в sitemap — через `xhtml:link`. Страница, у которой нет готовой версии на втором языке, выходит только на своём языке и без hreflang на отсутствующую пару. Ист.: `docs/22` R-9.10.

**Л-6. Готовность языка по странице.** Версия страницы индексируется, только если на этом языке переведены все обязательные блоки (≥ 90 % блоков по перечню типа, R-9.10) и есть собственный текст ≥ 300 знаков. Иначе `noindex` и без hreflang. Ист.: `docs/22` R-9.10, R-5.1.

## 3. Слои локализации

| Слой | Что локализуется | Источник текста | Ограничение |
|---|---|---|---|
| Строки интерфейса | кнопки, подписи фильтров, пустые состояния, подсказки «ослабь условие» | файлы языков (`ru.json` есть; `en.json` создать) | числа и множественные формы — через формат сообщений (см. раздел 4) |
| Шаблоны мета | `title`, `description`, `h1`, OpenGraph | `docs/23` | длины и порядок обрезки зависят от языка (Л-12) |
| Справочники сущностей | названия стран, городов, вузов, направлений, профессий, языков, уровней, форм обучения | база портала + внешние справочники | по полям из раздела 5 |
| Данные программ | названия программ, описания | источник данных | автоматический перевод запрещён (Л-9) |
| Редакционные тексты | тексты о стране, городе, направлении, профессии | редакция | отдельно на каждом языке; перевод — только с проверкой |
| Числа, даты, валюты | форматы | правила языка | раздел 6 |
| Графика | карточки OpenGraph | генерация | текст на картинке — на языке страницы |

## 4. Ограничения, которые надо решить

### 4.1 Грамматика

| Ограничение | Русский | Английский | Решение |
|---|---|---|---|
| Падежи названий | «в Германии», «из Казахстана», «в Германию», «рядом с Британским музеем» | нет падежей, но есть предлоги и артикли | поля справочников: `name_in`, `name_gen`, `name_to`, `name_ins` (ru); `name_in`, `name_from`, `name_to` (en), т. е. готовая фраза с предлогом (П, ОЛ-1) |
| Артикли | нет | «the Netherlands», «the UK», «the UAE», «the Philippines» | поле `name_the` у стран (en) |
| Множественное число | три формы (1 программа, 2 программы, 5 программ), особые 11–14 | две формы | правила CLDR; реализация через формат сообщений, не конкатенация строк (Л-8) |
| Род и согласование | «бесплатные программы», «бесплатное обучение» | нет | в шаблонах не склеивать прилагательные и существительные из разных полей; использовать готовые формы |
| Прилагательные от стран и городов | «немецкие вузы» | «German universities» | готовые поля `adj`, а не вычисление суффиксов |
| Падеж направления и профессии | «на разработчика ПО» | «software developer» | `name_acc` у профессий для ru (T26); en не требует |
| Язык обучения | «на английском», «на немецком» | «in English», «in German» | поле `lang_on` у языков |
| Составные числа и единицы | «42 месяца», «3 года» | «42 months», «3 years» | единицы времени через формат сообщений |

Ф: этих полей в базе, по входам, нет (`docs/23` М-5). Без них шаблоны не запускаются; страница без нужных форм не становится `indexable`.

### 4.2 Названия

**Л-7. Названия вузов, программ, улиц.** Хранятся три значения: `name_original` (как в источнике), `name_en`, `name_ru`. Показ на странице: язык страницы, при отсутствии — оригинал. Для вузов вне Латиницы и кириллицы — транслитерация по таблице, а не машинный перевод. Для широко известных вузов (традиционные русские названия) — ручной справочник. Ист.: П.

**Л-9. Запрет машинного перевода имён собственных и данных.** Названия программ, вузов и описания из источника не переводятся автоматически на странице. Допустимо: машинный черновик редакционного текста, который публикуется только после проверки (`reviewed_by`, `reviewed_at`). Ист.: П, `docs/05` (достоверность важнее полноты).

**Л-10. Справочники направлений и профессий.** CIP (направления): английский первоисточник; O*NET: только английский; ESCO: несколько языков, включая русский (П: проверить по актуальной версии); русские названия остальных — курируемый справочник. Пробел: объём курируемого перевода неизвестен, считается запросом в `docs/prompts/seo-volume-count.md`.

### 4.3 Данные и стиль

**Л-11. Орфография английского.** Американский вариант (program, license) по умолчанию. Причины: источники данных (CIP) американские; британский вариант — для рынка Великобритании по отдельному решению. Ист.: П, ОЛ-2.

**Л-12. Длины мета по языкам.** Кириллица шире латиницы на 10–20 % в пикселях (П): цели для `title` — en ≤ 60, ru ≤ 55 знаков; жёсткий предел 70 для обоих; для `description` en 110–160, ru 100–150, жёсткий предел 180. Реализовано в образцах (панель каждой страницы показывает длины). Ист.: `docs/23`.

**Л-13. Бренд.** Всегда `MainExperts` латиницей. Подзаголовок «от Mainexperts» убран (решение 13.11.2026).

**Л-14. Названия методик.** BFAS/Big Five и RIASEC не используются ни на одном языке; рабочие названия типов работы переводятся парой (ru «с людьми», en «working with people») (П, ОЛ-3).

### 4.4 Форматы

| Что | en | ru | Правило |
|---|---|---|---|
| Число | 22,638 | 22 638 (неразрывный пробел) | по языку страницы |
| Десятичная | 1.1 km | 1,1 км | по языку |
| Валюта | 3,000 EUR per year | 3 000 EUR в год | код валюты вместо символа в карточках; в мета — символ допускается «€» только в ru (П); в en используется «EUR» |
| Даты | 5–19 July 2027 | 5–19 июля 2027 | названия месяцев в справочнике, не из системной локали сервера |

| Единицы расстояния | km, m | км, м | метры и километры в обоих (US-мили не используются, П) |

### 4.5 Поиск и навигация

**Л-15.** Поиск работает по названиям на обоих языках и по оригиналу: запрос «Heidelberg», «Гейдельберг» и «Хайдельберг» ведёт к одной сущности (синонимы в справочнике). Морфология: русская (`seo-platform/03-search.md`) и английская (приведение к основе). Ист.: ПС.

**Л-16. Фасеты и счётчики.** Подписи значений фильтров берутся из справочников языка; счётчики не зависят от языка. Мультивыбор в T43 адреса не получает (R-4.3.2 `docs/22`).

### 4.6 SEO по языкам

| Тема | Правило |
|---|---|
| sitemap | отдельные шарды по типу и языку (`docs/22` R-9.2); `lastmod` по хэшу данных языковой версии |
| Каноникал | страница указывает на себя на своём языке; кросс-языковой canonical запрещён |
| Дубли | английская и русская версия — не дубли при корректном hreflang; запрещены страницы с английским текстом на `/ru/` и наоборот (смешанный язык) |
| Вебмастера | профили по языковым каталогам: Яндекс для ru, Google для en и MENA (П, проверить) |
| Метрики | доля индексации и показы — отдельно по языку; решение «снять» принимается по языку, не по сущности |

### 4.7 Качество и процесс

**Л-17. Словарь терминов.** Единый глоссарий «en ↔ ru» (программа, степень, форма обучения, бюджетные места, грант, срок подачи, набор, зачисление и т. д.). Правило: один термин — один перевод на всём сайте; глоссарий обязателен для редакции и проверки.

**Л-18. Тесты.** Псевдолокализация (удлинённые строки, проверка вёрстки); проверка длин `title` и `description`; поиск непереведённых ключей (ноль на индексируемых страницах); проверка множественных форм на числах 1, 2, 5, 11, 12, 21, 22, 25, 111; отсутствие кириллицы на `/en/` и латиницы вне названий на `/ru/` (кроме собственных имён, кодов, ссылок).

**Л-19. Правовые тексты.** Политика конфиденциальности, согласия, дисклеймеры о данных несовершеннолетних (`docs/05`) переводятся только по согласованию с юристом; машинный перевод запрещён.

**Л-20. Аналитика.** Язык страницы — измерение во всех метриках; UTM и цели не зависят от языка.

**Л-21. Редакционные блоки режима контента** (`docs/22`, 4.4) пишутся по одному фасету на каждом языке отдельно; перевод с другого языка публикуется только после проверки. Объём работы: блоки на (страна назначения) + (страна отправления) + (уровень) + (язык обучения) + (год) + (направление), а не на каждую комбинацию; оценка числа блоков вынесена в `docs/prompts/seo-volume-count.md`.

## 5. Модель хранения (П)

| Таблица | Поля |
|---|---|
| `entity_i18n` | `entity_id`, `locale`, `name`, `name_short`, `name_in`, `name_from`, `name_to`, `name_gen`, `name_ins`, `name_acc`, `name_the`, `adj`, `description`, `status` (черновик / проверено), `source`, `reviewed_by`, `reviewed_at` |
| `ui_strings` | `key`, `locale`, `value` (формат сообщений с формами множественного числа), `status` |
| `glossary` | `term_en`, `term_ru`, `note` |
| `page_i18n_state` | `page_key`, `locale`, `blocks_translated_share`, `text_chars`, `indexable` |

Решение по технологии (ОЛ-4): формат сообщений и правила множественного числа берутся из CLDR (ICU MessageFormat либо Fluent); для Rust есть библиотеки `fluent-rs` и `icu4x`. Падежи не выражаются ни одним из этих форматов, поэтому остаются полями справочника.

## 6. План по этапам

| Этап | Что | Условие входа | Результат |
|---|---|---|---|

| 4. Английские страницы | включить `/en/` для типов T01–T09, T20–T23, T43 с порогами; sitemap и hreflang | этапы 2, 3 | английская версия в sitemap |

Очерёдность английского и русского: английские справочники и шаблоны делаются первыми (этап 2), русские поля падежей — параллельно (этап 3); в sitemap английская версия включается раньше (этап 4). Русская версия при этом не ждёт английских редакционных текстов.

## 8. Критерии приёмки

| № | Сценарий | Ожидание |
|---|---|---|
| 1 | Любая индексируемая страница | есть пара на втором языке или `noindex` без hreflang (Л-6) |
| 2 | `/en/` без кириллицы вне собственных имён | 0 нарушений |
| 3 | Множественные формы на числах 1, 2, 5, 11, 12, 21, 22, 25, 111 | «program / programs», «программа / программы / программ» по правилам |

## 9. Проверка по правилам проекта

- Названия методик (BFAS/Big Five, RIASEC) не используются; рабочие названия — пара ru/en (ОЛ-3).
- Данные несовершеннолетних и правовые тексты — по согласованию с юристом (Л-19).
- Машинный перевод данных запрещён, черновики только с проверкой (Л-9).
- Разметка факт, предложение и пробел выдержана; цифры источников не изменены.
