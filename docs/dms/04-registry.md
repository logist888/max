# 04. Полный реестр документов

> Раздел 5 модуля DMS. Снимок 12.07.2026. Авторская разработка (Claude Code). Реестр —
> максимально полный каталог управленческих документов компании MainExperts на стадии
> «строится с нуля». Классы и словарь — по `03-classification.md`; процессы — по
> `02-process-map.md`; Divisions — по `01-divisions.md`. Утверждает основатель.

Это **мастер-реестр** (сам по себе документ класса Реестр, ID `D5-RGS-01`). Каждая строка —
управляемый документ с decision-релевантными атрибутами. Полные 30-полевые карточки
приоритетного набора — в `05-cards.md`; матрицы связей — в `06-matrices.md`.

## Как читать реестр

Колонки: **ID** (схема `Dn-CLS-nn`, см. `03-classification.md`, 4.8) · **Документ** ·
**Класс** (код класса) · **Кат** — категория происхождения `[О]` общепринятый / `[Р]`
рекомендуемый / `[А]` авторское (не смешиваются, разд. 4.9) · **MoSCoW** (M/S/C/W) · **Крит**
(критичность: Cr/H/M/L) · **Зрел** — уровень зрелости, на котором документ становится
необходим (MVP/Gr/Sc/Ent) · **Владелец** (роль-архетип; факт-владельцы — в `06-matrices.md`) ·
**Авт·AI** — потенциал автоматизации ведения (низ/сред/выс) · возможность AI-генерации
(да/част/нет) · **Проц** — обслуживаемый процесс(ы).

> Оговорка: MoSCoW, критичность и зрелость — авторская `[оценка]` для стадии 07.2026; при
> смене стадии пересматриваются. Владельцы — целевая оргструктура; сейчас роли совмещены в
> основателе и узком круге (та же оговорка, что у бордов MMS).
