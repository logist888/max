# D2-CLF-02 · Классификатор посадочных страниц `PG_`

> **Паспорт.** ID `D2-CLF-02` · класс Классификатор (CLF) · Division D2 · уровень тактический ·
> версия v1.0 · статус: **СОБРАН** (перенос существующего содержания).
> **Источник:** `../../12-traffic-platform-decisions.md`, блок **Б** «Паспорта элементов
> платформы (словари LST_ / PG_)» — перенесено из таблицы источника, не сочинено.
> **Где упомянут:** `../04-registry.md` (D2-CLF-02), `../05-cards.md` (шаблон карточки).

**Закрытый словарь воронковых/вирусных страниц.** `PG_*` — страницы, на которые ведётся трафик;
транзакционные карточки — отдельный словарь `LST_*` (см. `D4-CLF-01`).

| `PG_`-ключ | Что это | Тип | Целевое событие | Готовность |
|---|---|---|---|---|
| `PG_QUIZ` | Квиз — бесплатный скрининг | воронк. | `EVT_SCREENING_DONE` (+ `EVT_REG`) | в работе |
| `PG_PROFILE10` | Профиль 10 в кабинете (бесплатный, апселл диагностики) | воронк. | `EVT_PROFILE10_ACTIVATED` | в работе |
| `PG_WEBINAR` | Лендинг вебинара | воронк. | `EVT_WEBINAR_REG` | в работе |
| `PG_HOME` | Главная страница | воронк. | `EVT_GOTO_QUIZ` (переход вглубь) | есть |
| `PG_CAT_PROF` / `PG_PROF` | Категории и карточки профессий (база O*NET, ESCO ≈ 3 тыс. позиций) | воронк. | `EVT_GOTO_QUIZ` | не начато |
| `PG_ART` | Блог, статьи | воронк. | `EVT_GOTO_QUIZ` | не начато |
| `PG_ACCOUNT` | Личный кабинет | воронк. | возврат, использование, продление | есть (~80%) |
| `PG_SHARED` | Страница расшаренного результата, обезличенная | вирусн. | `EVT_GOTO_QUIZ` («пройти самому») | не начато; **без ПДн ребёнка — юр. ограничение** (`../../05-risk-compliance.md`) |
| `PG_PARTNER_*` | Ко-брендовые страницы партнёрств | воронк. | по соглашению | по мере соглашений |
| `PG_PROMO_*` | Промо-лендинги кампаний | воронк. | по кампании | по мере кампаний |
| `PG_MARKET` | Каталог услуг (маркетплейс) | воронк. | просмотр карточек → заказ | скрыт до прихода внешних провайдеров |

## Инвариант (из источника)

**`PG_HOME` не бывает основной посадочной платного холодного трафика** — нет одного целевого
действия, размывает измерительную ячейку (`../../12-…` §Г1).
