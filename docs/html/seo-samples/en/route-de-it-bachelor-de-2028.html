How admission works: bachelor’s in Germany

For a bachelor’s degree you need a school-leaving certificate that German universities recognise as giving access to higher education. Depending on the country that issued the certificate, some applicants must first complete a one-year preparatory course (Studienkolleg) or pass an assessment test. Applications from abroad are often handled centrally by the service uni-assist, while some universities accept applications directly.

Language: studying in German

Programs taught in German normally ask for a German proficiency certificate, such as TestDaF or DSH. The required level depends on the university and program, and it is usually higher for technical and academic subjects. Plan enough time for language preparation before the application deadline.

2028 intake: timeline

  • October 2027 — Choose the language test and start preparing
  • January 2028 — Applications for the winter intake start to open at many universities
  • July 2028 — Typical application deadline for the winter intake (check each university)
  • August 2028 — Admission decisions, visa and housing
  • October 2028 — Winter semester starts
Dates are typical for the winter semester and are given as a planning guide. Exact deadlines are set by each university.

Documents to prepare

school-leaving certificate with a transcript of grades (certified translation if required); proof of language; passport copy; CV (some programs); motivation letter (some programs); proof of preparatory course or entrance test where applicable.

Is IT the right field for you?

IT covers software development, data and artificial intelligence, cybersecurity, networks and information systems. Programs differ in how much theory and how much practice they include, so compare the curriculum, not only the name of the program. Related careers: software developer, data analyst, cybersecurity specialist.

Frequently asked questions

Can I apply without German?

Not for a program taught in German: a German certificate is normally required. Look at English-taught programs if you do not speak German yet.

When should I start preparing for the 2028 intake?

Ideally about a year before the start, in autumn 2027: language test, documents and translations take longer than expected.

What is different for a bachelor’s applicant?

The main difference is the entry qualification: a school certificate for a bachelor’s degree, a bachelor’s diploma for a master’s degree.
