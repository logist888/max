## Назначение

Product Dashboard — основной инструмент управления продуктовым портфелем MainExperts (п. 10.1). Если Expert Dashboard отвечает на вопрос «Насколько эффективны эксперты?», то Product Dashboard отвечает на вопрос «Какие продукты создают максимальную ценность для клиентов и компании?». Главная задача борда — обеспечить принятие инвестиционных решений на основе объективной продуктовой аналитики.

Борд отвечает на вопросы (п. 10.1):

1. Какие продукты необходимо масштабировать?
2. Какие продукты становятся убыточными?
3. Какие продукты ограничивают рост компании?
4. Какие продукты следует закрыть?
5. Где необходимо инвестировать ресурсы?

Основные пользователи (п. 10.2): Chief Product Officer, Product Owners, CEO. Дополнительные: Owner, CFO, COO, CMO.

## Структура экрана

Борд скомпонован по зонам сверху вниз (ASCII-схема источника, п. 10.3):

| Зона | Содержание |
|---|---|
| Product Portfolio Summary | Агрегированные показатели портфеля |
| Product Matrix · Revenue Analysis | Матрица продуктов · анализ выручки |
| Contribution · Product Lifecycle | Contribution · жизненный цикл продукта |
| Adoption · Customer Satisfaction | Использование · удовлетворённость клиентов |
| Forecast · AI Product Insights | Прогноз · AI-аналитика по продуктам |
| Product Alerts | Автоматические предупреждения |

| KPI | Что показывает | Формат/единица | Порог/статус |

Каждая карточка отображает (п. 10.4): текущее значение; изменение; тренд; прогноз; AI Explain. Единый каркас карточки (значение, план, отклонение, тренд, цвет статуса, Drill Down, AI Explain, история) — см. [00-framework](00-framework.md).

## Product Matrix

Все продукты автоматически распределяются по матрице (п. 10.5). Оси: горизонталь — рост (Low Growth ↔ High Growth), вертикаль — Contribution (низкий ↔ высокий).

```
Высокий Contribution
  Strategic Products    │
  Low Growth ───────── High Growth
  Legacy Products       │   Experimental
Низкий Contribution
```

Квадранты (по подписям источника): Strategic Products — высокий Contribution; Legacy Products — низкий Contribution и низкий рост (нижний-левый); Experimental — низкий Contribution и высокий рост (нижний-правый).

> Пробел: в извлечённой ASCII-схеме привязка Strategic Products к колонке роста не однозначна, а второй верхний квадрант (высокий Contribution) не подписан — метки не достраивались.

Матрица обновляется автоматически после пересчёта KPI.

## Product Card

Каждый продукт имеет собственную карточку (п. 10.6) со следующими группами показателей:

| Группа | Показатели |
|---|---|
| Общая информация | название; код; владелец; категория; статус; дата запуска |
| Финансы | Revenue; Contribution; Margin; EBITDA Contribution; ROI |
| Клиенты | количество покупателей; повторные покупки; LTV; NPS; Retention |
| Производство | Capacity Consumption; Expert Hours; AI Usage; Delivery Time |
| Развитие | Roadmap; последние релизы; открытые задачи; инвестиции |

## Revenue Analysis

Выручка анализируется одновременно по нескольким измерениям (п. 10.7). Поддерживаемые разрезы: по продукту; по стране; по сегменту; по подписке; по эксперту; по каналу продаж; по периоду. Любой график поддерживает Drill Down.

## Contribution Analysis

Contribution рассчитывается отдельно для каждого продукта (п. 10.8). Структура расчёта:

```
Revenue
  ↓ Variable Costs
Contribution
  ↓ Fixed Allocation
Operating Profit
```

Борд позволяет определить продукты с наибольшим вкладом в развитие компании.

## Product Lifecycle

Каждый продукт имеет текущую стадию жизненного цикла (п. 10.9): Discovery; Validation; Launch; Growth; Maturity; Optimization; Sunset. Для каждой стадии отображаются собственные KPI. Примеры главных показателей по стадиям:

| Стадия | Главный показатель |
|---|---|
| Launch | Product Market Fit |
| Growth | темп масштабирования |
| Maturity | Contribution |

## Product Adoption

Контролируется использование продукта (п. 10.10). Основные показатели: активные пользователи; завершённые покупки; частота использования; глубина использования; повторные продажи; вовлечённость. Для цифровых продуктов дополнительно отображаются Daily Active Users и Monthly Active Users.

## Customer Satisfaction

Для каждого продукта рассчитываются (п. 10.11): NPS; CSAT; количество обращений; возвраты; рейтинг; повторные покупки.
