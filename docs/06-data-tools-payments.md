## Данные о профессиях

- **ESCO v1.2.1** — EU, около 3043 профессий.

Правило данных: профессии — объединённая база O*NET и ESCO; рынок труда РФ в реальном времени через api.hh.ru; зарубежные данные обновляются реже. Парсер рынка труда и зарплат — активный блокер (источник не найден). Есть отдельный рабочий инструмент «Промпт по расширению базы профессий» (на Диске), см. реестр артефактов в `07`.

## Маркетинг: четыре слоя трафика (Диск, 10.06.2026)

Трафик многослойный, каждый слой решает свою задачу, смешивать цели нельзя.

1. **Платный трафик (Meta, ВК).** Лиды на вебинар и скрининг (Профиль 10). Meta — основной канал (родители 35–50, СНГ плюс MENA), ВК — дешёвые лиды (мамы 25–45). Механика: трафик → квиз/лид-магнит → Профиль 10 → покупка. Лид-магниты на A/B: «7 ошибок, из-за которых дети теряют годы», «5 вопросов, которые откроют таланты», «Какие профессии исчезнут через 10 лет». Домен .ru НЕ работает с Facebook-рекламой, использовать mainexperts.online. KPI в файле: CPL около $3, бюджет запуска $1500–2000, скрининг → регистрация >40%, регистрация → покупка 50К >5%.
2. **SEO.** Стратегия перемножения характеристик (по аналогии с kolesatyt.ru Игоря, рост 394 млн → около 1 млрд за 2 года): тысячи страниц через комбинации атрибутов (возраст × тип × география × пол × запрос). WordPress плюс плагин генерации. 500–1000 страниц за первый месяц, через 3–6 месяцев агрегатор «Топ профориентации РФ».
3. **Контент (соцсети, YouTube).** Доверие и органические лиды, основа для пакетов 500К+. Аккаунты: mainexperts (английский, глобальный), mainexperts_russia (русский, СНГ). Видео Макса, Telegram-канал. Принцип: каждый пост даёт необратимую пользу читателю.
4. **Нетворкинг и рекомендации.** HNW/UHNW для пакетов 500К, 1.5 млн, Family Office. Нетворкинг Макса в Дубае, private banking, партнёрства, реферальная программа. Макс — лицо канала. Это поток 1.

**Расхождение с актуальным.** Вебинар в файле 16 июня (актуально 4 июля). CPL как KPI — память подчёркивает: ДРР важнее CPL, CPL лишь прокси. Пакетная лесенка — до сдвига 17–18.06.

Концепция синтетических профилей (Social Learning, аналогия Social Investing Тинькофф) — см. юридический статус в `05-risk-compliance.md`: живые люди без согласия запрещены, безопасны обезличенные архетипы.

## Аналитика

Яндекс.Метрика плюс Google Analytics плюс Google Data Studio. Карта UTM-меток (партнёрские: utm_source=партнёр, utm_term=фамилия). **ДРР (доля рекламных расходов от выручки) — основной KPI**, CPL — прокси. Нужна сквозная аналитика: лид → конверсия → LTV. Ключевой KPI по Максу — ДРР.

Фон Игоря: вёл kolesatyt.ru (шины/диски, рост с 394 млн до около 1 млрд за 2 года); участвовал в госпроекте «Демография» (Татарстан): квиз → колл-центр, 800К лидов/год. Вывод: вебинарная воронка эффективнее колл-центра.

## Платежи

- **Робокасса** — зарубежные карты Visa/MC, комиссия 10%, рубли на ИП.
- Meta-реклама — через Вадима (Грузия) или USDT.
- Следующий шаг: Stripe плюс дубайское юрлицо (трек mainexperts.com).
- Ответственный за платежи и сведение оплат с источником трафика вручную — Даниил (cross-domain до Робокассы автоматически не связать).

## Инструменты и генерация (рабочие приёмы)

- **Google Drive MCP**: только create / read / copy / search / metadata / permissions. Без delete, rename, overwrite. Текстовые файлы: contentMimeType text/markdown плюс disableConversionToGoogleType true. Бинарные (Excel, PDF): base64 через base64Content (крупные PDF могут не пройти в один вызов). Поиск по папке: parentId = '[folder-id]' and title contains '[term]'.
- **Правило двух версий**: в папке Диска всегда ровно две версии файла (актуальная плюс предыдущая). При обновлении создаётся новая, указывается, какой файл удалить — удаляется вручную (MCP не умеет удалять).
- **Генерация PDF**: ReportLab плюс DejaVu Sans TTF (все 4 начертания плюс registerFontFamily) — единственный надёжный путь для кириллицы.
- **Excel**: openpyxl через bash; freeze panes на D3; пастельные заливки через интерполяцию RGB к 255.
- **ИИ на платформе**: OpenRouter (анализ сертификатов экспертов, можно переключить на Claude); отчёты — очередь по 5.
