# 13. Борд 13 · System Map — интерактивная карта «Трафик → Платформа → Решения»

Снимок 09.07.2026. Точка входа в тринадцатый артефакт комплекта (после документов 01–12).
Это **инструмент**, а не текст: production-ready React SPA в каталоге `board-13/`, которая
визуализирует весь операционный слой привлечения как живую карту. Рабочий контекст, не выверенный
источник — факты для клиентских материалов перепроверять с датой и первоисточником.

> Scope — **только Поток-2** (воронка семей). Поток-1 не затронут; экспертная сторона
> (`MK_REF_EXPERT`, подписка экспертов) вынесена и не агрегируется. Полное соблюдение границ
> из `12-traffic-platform-decisions.md`.

## Что это

Борд, отвечающий на вопрос: **как устроена система привлечения и где принимается каждое решение**.
После запуска карта позволяет: понять архитектуру за 30 секунд; найти любой объект за секунды;
увидеть все зависимости; понять поток данных; понять правила принятия решений; работать как
рабочая документация для CMO, Growth Lead, аналитиков, разработчиков и подрядчиков.

Источник данных борда — `12-traffic-platform-decisions.md` (снимок 08.07.2026): закрытые словари
`MK_` / `PG_` / `LST_` / `REF_` / `CELL_`, матрица «источник → посадочная → действие → запрет»,
учётный контур и цикл решений. Всё знание борда лежит в словарях `board-13/src/data/*`; интерфейс
их только отображает.

## Место в системе бордов (оговорка по нумерации)

Семь **управленческих** бордов MMS (L0–L1) пронумерованы в `boards/` как `10-owner`…`16-product`
(см. `08-board-system.md`). «Борд 13» здесь — **не** борд Sales из того реестра, а тринадцатый
артефакт комплекта документации (доки 01–12 → карта 13). По назначению это **операционный борд
маркетинга**: визуальный слой поверх `boards/12-marketing.md` (KPI лиды/конверсии/ДРР) и
операционного документа 12. При сведении в единый реестр его следует помечать как
System Map / Traffic-Platform-Decisions, чтобы не путать с L1-бордом Продаж.

## Семь слоёв (сверху вниз)

`TRAFFIC → LANDINGS → PLATFORM → ANALYTICS → DECISIONS → CELL → CONTRACTOR`.

- **TRAFFIC** — 22 источника `MK_*` (канал, рынок, температура, формирование, рычаг, скорость
  отклика, владелец).
- **LANDINGS** — посадочные `PG_*` / `LST_*` + правила связей (допустимые и запрещённые, с причиной).
- **PLATFORM** — пользовательский поток и сквозная цепочка событий `EVT_*` / заказов `ORDER_*`
  (клик → посадочная → скрининг → Профиль 10 → регистрация → активация → заказ → оплата → членство →
  продление); точка сшивки — регистрация (`client_id` → `user_id`).
- **ANALYTICS** — учётный контур: рекламная площадка → GA/Метрика → платформа → единая витрина →
  дашборд → Decision Engine; пробелы контура (импорт расхода, сшивка) помечены явно.
- **DECISIONS** — метрики с порогами (светофор) и дерево решений: CTR↓ → сменить креатив; CR
  посадочной↓ → чинить посадочную; CR рег→заказ↓ → пауза, разбор оффера; ДРР ≤ зелёный + объём →
  масштабировать; ДРР↑ → остановить ячейку.
- **CELL** — измерительные ячейки `CELL_*`, центральный объект: все решения принимаются относительно
  ячейки (источник × посадочная × рынок × вариант; бюджет ≥ $400; «одна кампания — одна посадочная»).
- **CONTRACTOR** — шаблон ТЗ подрядчику (канал, ячейка, посадочная, UTM, бюджет, KPI, запреты,
  отчётность, стоп-правило).

## Пометки достоверности (правило данных проекта)

- **[ГИПОТЕЗА]** центральная ставка: «скрининг оцифровывает страх родителя → родитель покупает
  диагностику». Метрика `CR рег → ORDER_DIAG` и возвраты помечены как гипотеза везде, где на них
  опирается решение — до подтверждения на холодном трафике (E0/E-AI, `docs/11`).
- **[ЦЕЛЬ]** пороги CPL/CR/ДРР — целевые ориентиры, не замеры; калибруются после микро-теста.
- **[ОЦЕНКА]** ячейки `CELL_*` в поставке — примерные, для демонстрации; реальные заводятся так же,
  только данными.
- **Главный технический блокер** — учётный контур: без импорта расхода и сшивки `client_id` →
  `user_id` истинный ДРР не считается; до этого канал ведётся по прокси (CPL + CR посадочной).

## Как запустить

```bash
cd board-13
npm install
npm run dev      # http://localhost:5173
```
