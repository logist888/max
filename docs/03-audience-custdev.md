## Ключевые боли аудитории

Потеря времени («потерянные годы» ребёнка) — главный страх. Непонимание интересов и талантов ребёнка. Страх навязать неправильный путь. Отсутствие мотивации у ребёнка. Коммуникационный разрыв с ребёнком. KPI успеха для клиента: внутренняя мотивация ребёнка плюс конкретный результат (поступление).

## Подтверждённые custdev-инсайты (семьи)

- Отчёт плюс консультация эксперта обязательны (8 из 9).
- Премиальный дизайн (9 из 9).
- Цена вторична репутации (9 из 9).
- Видеозвонок перед покупкой (7 из 9).
- Доверие через рекомендации важнее демонстрации экспертизы.

Опровергнуто: научность некритична; бизнес-презентация не нужна; промежуточные апдейты не нужны.

Главный поведенческий инсайт (лёг в основу CJM): клиент получает отчёт, впечатляется и не знает, что делать дальше. Нет следующего шага. Отсюда вся логика триггеров после отчёта, см. `04-operations.md`.

## Custdev: сегмент экспертов

Пресечена ловушка подтверждения предубеждений: Denis — тёплый контакт, валидировал потребность в лидогенерации, одновременно подтвердив, что платформа её пока не обеспечивает. Следующий этап — холодная выборка респондентов.

Ключевые боли экспертов (валидировано): неоплачиваемое время интейка, нагрузка от перепланирования, тревога координации платежей.

Методология-маркетплейс: интерес подтверждён, юридический вопрос по IP не закрыт, разработка заблокирована.

## Три цели раннего привлечения экспертов (держать раздельно)

Валидация продукта; проверка гипотезы скрининга; накопление пользовательского опыта. Смешение даёт ложные выводы. Разрезы аудитории и продукта в этом снимке размечены под валидацию продукта и проверку гипотезы скрининга.

## Custdev-ловушка предвзятости (принцип)

Тёплый контакт, знающий проект, — максимально смещённый респондент. Боль может быть реальной, а готовность платить — нет. Это правило применяется ко всем интервью.

## Кто клиент платформы — управленческое решение (24.06.2026)

До этого снимка персонажи описывались только как родители. На созвоне 24.06.2026 (аналогия банка «Точка»: вопрос «кто ваш клиент» на стратегической сессии банка сузил аудиторию до предпринимателей) команда явно поставила тот же вопрос себе. Итог — **два сценария признаны равноприоритетными**: «подросток при участии родителя» и «родитель/взрослый с подростком». Приоритет одного сценария над другим по конкретным каналам (реклама, вебинар) не финализирован — решается отдельно на этапе запуска. Дополнительная аналогия: семья как группа приравнена к корпоративной группе (родитель ≈ выделяет бюджет и поддержку, подросток ≈ департамент, который должен дорасти до самостоятельности). Подробно: `vault/20-notes/2026-06-24-client-is-teen-and-parent.md`.

## Дополнительные custdev-кейсы (устно, без имён, 24.06.2026)

Иллюстрации принципа «эксперт плюс психолог обязательны» и «работаем с первопричиной, не с симптомом» (см. выше подтверждённые инсайты): корректировка цели вместо форсирования результата (кейс с непроходными баллами колледжа → добавлен год обучения = foundation year); психологическая работа с внутренними ограничениями подняла результат экзамена с ~50 до 95–98 баллов при минимальной доработке техники; принцип «не любой ценой за результат» — агентство не давит на подростка, если он в моменте передумал, даже вопреки договорённости с родителем. Кейсы устные, без даты/источника в смысле правила премиум-факта — годятся для внутреннего понимания подхода, не для клиентских материалов. Подробно: `vault/20-notes/2026-06-24-custdev-case-examples.md`.

## Таксономия болей семьи — черновая, не валидирована (25.06.2026)

Сгенерирована через ИИ таблица на 13 000+ строк (комбинации возраст ребёнка × возраст родителя × страна × доход), сведена в 15 областей боли: будущее/профессия/заработок; сильные стороны/талант; образовательный путь; оценки/экзамены/поступление; мотивация/привычки/цифровая среда; психическая устойчивость/тревога; доверие/границы с ребёнком; сверстники/принадлежность; безопасность/рискованное поведение; переезд/язык/адаптация; учителя/наставники; согласие взрослых и семейные ожидания; деньги/самостоятельность; здоровье/сон; правовой статус/визы. **Статус: черновик, команда сама признала его непроверенным** («либо ценность, либо полный хейт») — не использовать как основу для расчёта профиля до проверки; потенциально годится как источник тем для контента.
