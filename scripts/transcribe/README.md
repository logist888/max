# Транскрипция по говорящим

Превращает запись созвона (Google Meet, Zoom, диктофон) в текст, где у каждой
реплики стоит говорящий и таймкод. Работает локально на процессоре: ни ключей,
ни отправки записи наружу. Это существенно — на записях идут имена клиентов,
цены и данные несовершеннолетних.

## Установка

```bash
scripts/transcribe/setup.sh
```

Ставит ffmpeg, `faster-whisper`, `sherpa-onnx` и две модели диаризации (35 МБ).
Модель распознавания (1.6 ГБ) скачивается сама при первом запуске. Контейнер
эфемерный — после пересоздания скрипт запускается заново.

## Запуск

```bash
python3 scripts/transcribe/diarize_asr.py raw/встреча.webm -o transcripts/
```

Полезные ключи:

| Ключ | Смысл |
|---|---|
| `-s 4` | известно число говорящих — задать явно, точность выше |
| `--threshold 0.45` | в авторежиме: ниже порог → больше голосов |
| `--beam 5` | точнее распознавание ценой ~1.5× времени |
| `--names names.json` | подставить имена вместо «Говорящий 1» |
| `--no-diarize` | сплошной текст без разделения по голосам |
| `-l en` | другой язык (по умолчанию русский) |

На выходе четыре файла: `.md` (для чтения и работы), `.txt` (то же содержание без
разметки), `.srt` (субтитры к видео), `.json` (машинная обработка). Пятый файл —
`.summary.html`, выжимка под постановку задач — не генерируется скриптом: её
собирает модель, прочитав транскрипт (порядок в скилле `transcribe`).

## Имена вместо номеров

Диаризация различает голоса, но не знает, как зовут людей. Имена берутся одним
из двух способов.

**По картинке записи.** Telemost, Meet и Zoom подсвечивают плитку говорящего
рамкой, а подпись под плиткой — это имя участника. Скрипт снимает кадры,
находит подсветку, читает подпись и отдаёт интервалы «имя говорит»:

```bash
python3 scripts/transcribe/video_speaker_tags.py raw/встреча.webm -o transcripts/.work/встреча.tags.json
python3 scripts/transcribe/diarize_asr.py raw/встреча.webm -o transcripts/ \
        --video-tags transcripts/.work/встреча.tags.json
```

Подсветка — сигнал надёжнее кластеризации голосов: она привязана к участнику, а
не к тембру. Поэтому слово внутри интервала с одним активным участником получает
имя напрямую, а разделение по голосам закрывает промежутки — кадры с несколькими
подсветками и участки без них, где имя выбирается среди активных по тому, что
чаще доставалось словам этого кластера. Шапка транскрипта показывает долю
каждого способа. Требуется `tesseract-ocr` с русским языком (ставит `setup.sh`);
без него остаются номера плиток.

**Вручную.** По началу записи (представления, обращения по имени) составить карту

```json
{"0": "Максим", "1": "Игорь", "2": "Анна"}
```

и пересобрать с `--names`; ручная карта перекрывает имена из видео. Промежуточные
результаты кешируются в `transcripts/.work/`, повторный прогон занимает секунды.

## Как устроено

| Шаг | Инструмент | Что делает |
|---|---|---|
| 1 | ffmpeg | контейнер → WAV 16 кГц моно |
| 2 | sherpa-onnx: pyannote segmentation-3.0 + CAM++ | размечает, кто и когда говорит |
| 3 | faster-whisper large-v3-turbo (int8) | распознаёт речь с таймкодами по словам |
| 3.5 | `video_speaker_tags.py` (необязательно) | читает имя активного участника с картинки записи |
| 4 | сшивка | слово получает голос по наибольшему перекрытию, слова собираются в реплики |
| 5 | экспорт | md / txt / srt / json |

Необязательный шаг — `video_speaker_tags.py`: разметка активного говорящего по
подсветке плиток в видео. Даёт реальные имена и служит проверкой диаризации:
где два независимых сигнала (голос и картинка) расходятся, там и стоит смотреть.

## Чего ждать по скорости и качеству

Замер на записи 85,8 минуты, четыре ядра: распознавание 34 минуты, разделение
по голосам 10 минут, разбор видео 4 минуты. Память — до 4 ГБ.

Известные ограничения, они же места ошибок:

- **Перекрывающаяся речь.** Когда двое говорят разом, реплика уйдёт одному.
- **Короткие вставки** («да», «угу») часто липнут к соседнему голосу.
- **Похожие голоса** в авторежиме могут слиться в один — лечится ключом `-s`.
  Обратная беда: авторежим дробит один голос на десятки кластеров. Лечится
  ключом `-s` по числу участников либо разметкой из видео, которая схлопывает
  дубли в одно имя.
- **Термины, имена, англицизмы** распознаются с ошибками; числа и суммы
  перед использованием сверяются с записью.
- **Галлюцинации** на тишине и музыке: VAD их режет, но не полностью.

Транскрипт — сырьё для работы, а не документ. Цифры и цитаты, идущие
в материалы клиентам, проверяются по исходной записи.
