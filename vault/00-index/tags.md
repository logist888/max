# Метки

Использовать только из этого списка; новую метку сначала добавить сюда.

## Обязательные поля (не метки, а frontmatter)
- `stream`: `поток-1` | `поток-2` | `общее`
- `status`: `факт` | `гипотеза` | `требует-проверки`
- `goal` (тема экспертов): `валидация` | `гипотеза-скрининга` | `опыт` | `н/д`
