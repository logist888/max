# Промпт-задание: расширение базы профессий до полного масштаба

> Назначение: запустить в режиме глубокого исследования (Research) для наполнения
> информационного слоя Профиля 360 реальными данными на сотни профессий.
> Главное правило, которое нельзя нарушать: **ни одной цифры без источника и даты.**

---

## Контекст для исполнителя

Ты собираешь внутреннюю базу данных о профессиях для образовательной платформы
профориентации (рынки: Россия/СНГ, MENA/Залив, Великобритания, глобально, Китай).
База питает «информационный слой» в личном кабинете: показывает родителю и подростку,
как меняются профессии, какие исчезают под давлением ИИ, какие появляются, сколько
платят и какой риск автоматизации.

Аудитория — обеспеченные родители (HNW/UHNW). Один выдуманный факт обрушит доверие.
Поэтому точность и проверяемость важнее объёма и красоты.

---

## ЖЁСТКИЕ ПРАВИЛА (нарушение = брак работы)

1. **Каждая строка данных = источник + дата публикации + ссылка.** Нет источника —
   нет строки. Не заполняй пробелы «правдоподобными» цифрами.
2. **Не смешивай несопоставимые метрики.** «Экспозиция к ИИ» ≠ «прогноз сокращения
   занятости» ≠ «фактические увольнения». Указывай, что именно измеряет цифра.
3. **Не выдавай глобальные данные за локальные.** Если по конкретному рынку (особенно
   MENA, СНГ) данных нет — так и напиши: «локальных данных не найдено».
4. **Различай факт и прогноз.** Зарплата за 2025 — факт. «Профессия исчезнет к 2030» —
   прогноз конкретного отчёта, всегда с атрибуцией («по прогнозу WEF…»).
5. **Указывай частоту обновления источника** (live / ежемесячно / ежегодно / разово),
   чтобы было видно, что можно подтягивать автоматически, а что — раз в год.

## ЧТО НУЖНО СОБРАТЬ (по приоритету)

### Блок 1. США / глобал — машиночитаемые базы (наивысший приоритет)
- **O*NET** (onetcenter.org/database.html, ~900 профессий): по каждой — описание,
  навыки, зоны подготовки, связь с образованием. Свободно скачивается. Цель: вытащить
  таблицу профессий с кодами SOC и атрибутами.
- **BLS Employment Projections 2024–2034** (bls.gov/emp): по каждой из ~800 профессий —
  прогноз роста в % и абсолюте, медианная зарплата, типичное образование. Скачиваемые
  таблицы. Цель: полная таблица «профессия → рост → зарплата → требуемое образование».
- **BLS «AI exposure»** и исследования (Anthropic Economic Index, OpenAI/Penn, EDsmart
  784 профессии): уровень экспозиции к ИИ по профессиям.

### Блок 2. ЕС — таксономия
- **ESCO** (esco.ec.europa.eu, ~3000 занятий, API): структурированная связь
  «профессия ↔ навыки ↔ квалификации» на 28 языках. Цель: основа онтологии компетенций.

### Блок 3. Россия / СНГ
- **api.hh.ru + stats.hh.ru**: спрос (вакансии), конкуренция (резюме/вакансию),
  предлагаемые зарплаты по профобластям и регионам. Единственный live-источник.
- **Хабр Карьера, Минтруд РФ, Росстат**: зарплаты по IT-специализациям и грейдам,
  дефицит кадров, демографические прогнозы.
- **Атлас новых профессий (Сколково)**: профессии будущего (как прогнозный слой).

### Блок 4. Великобритания
- **GOV.UK LEO / Graduate Outcomes** (с 06.2026 — Graduate Labour Market Outcomes):
  заработок выпускников по специальности через 1/3/5/10 лет. Связка «вуз → доход».
- **ONS (SOC-коды)**: спрос и диапазоны зарплат по профессиям.

### Блок 5. Китай
- **Минобр КНР / Синьхуа**: реформа вузовских специальностей (что убрали/добавили),
  новые направления (embodied AI, brain-computer, intelligent imaging). Список вузов
  и конкретных специальностей, если доступен.

### Блок 6. MENA / Залив (ожидается бедный результат — это нормально)
- **Salary guides**: Korn Ferry, Michael Page, Hays, Robert Half, Mercer — зарплаты и
  прогнозы по ОАЭ/КСА/Катару. Отметь, что платно и какова цена доступа.
- **Государственные источники GCC**: министерства труда (часто на арабском/закрытые).

### Блок 7. Новые и исчезающие профессии (сквозной)
- Emerging-роли последних 3–5 лет (prompt-инженер, AI ethics, embodied AI и т.д.)
- Профессии под наибольшим риском исчезновения с атрибуцией прогноза.

## ФОРМАТ ВЫДАЧИ

Для каждой профессии — строка со следующими полями:

| Поле | Пример |
|------|--------|
| Профессия | Дата-сайентист |
| Рынок | Россия / США / UK / MENA / Китай / Глобал |
| Категория | ИИ-данные / здравоохранение / ремёсла … |
| Динамика | рост +28,5% (2024–34) / исчезает / новая |
| Зарплата | медиана + валюта + год |
| Риск ИИ | низкий / средний / высокий + чем измерен |
| Требуемое образование | если есть |
| Источник | название + дата + ссылка |
| Частота обновления источника | live / ежегодно / разово |

Дополнительно по каждому источнику — карточка:
- стоимость доступа (бесплатно / платно + цена, если известна),
- наличие API / машиночитаемость,
- дата последней публикации,
- ограничения (язык, лицензия, перепубликация).

---

## ОБЪЁМ И ПРИОРИТИЗАЦИЯ

- Цель-минимум: 300–500 профессий с полями выше, из них ≥150 — из машиночитаемых
  баз (O*NET, BLS, ESCO).
- Если ресурс ограничен — сначала Блоки 1–4 (они дают больше всего проверяемых данных),
  затем 5–7.
- В конце — сводка покрытия: по каким рынкам данные плотные, по каким дыры, и явный
  список того, что осталось недоступно (с причиной: платно / на арабском / нет API).

---

## ЧЕГО НЕ ДЕЛАТЬ

- Не генерировать «список из 100 профессий» по памяти без источников.
- Не округлять и не «улучшать» цифры.
- Не объединять данные разных лет в одну строку без пометки.
- Не выдавать прогноз за факт.
- Не копировать длинные куски текста из платных отчётов (риск нарушения лицензии) —
  только числовые данные с атрибуцией.
