## Занятие 1 — продуктовый подход и качество
- Главное слово системы — **клиент**; главное слово продуктового подхода — **качество**.
- Каждый уровень (организация → подразделение → должность) создаёт ПРОДУКТ для КЛИЕНТА. Десятки внутренних продуктов «собираются» в 1–2 внешних. У каждого процесса свой клиент, требования, цепочка.
- Качество (ГОСТ Р ИСО 9000-2015): степень соответствия присущих характеристик требованиям.
- **12 вопросов продуктового подхода:** клиент и иерархия → продукт → требования к качеству → характеристики → сверка с требованиями → удовлетворённость → лояльность → выборка → процесс мониторинга → работа с браком → непрерывное улучшение → отчёт о качестве.
- **Логика качества (5 шагов):** продукт и характеристики → клиент и ожидания → совпали? → превзошёл? → как подтверждено.
- Метрики: **CSI** (удовлетворённость), **NPS** (лояльность/рекомендация). WOW-эффект для внешнего и внутреннего клиента, главный показатель WOW — NPS. Цепочка: клиент → продукт → качество → удовлетворённость → лояльность.
- **Продукт должности:** какой продукт создаёт сотрудник, за что платят, как мерим, кто его клиенты. Должностная инструкция = «что» (цели, показатели, продукт, клиент) + «как» (алгоритмы, регламенты), вся в логике PDCA.
- Шаблон-таблица (xlsx): № | Должность | Продукт должности | Показатели качества | Что формирует wow-эффект.

## Занятие 2 — качество через сотрудника (вовлечённость)
- Сотрудник как внутренний клиент: ожидания от компании, мотивация, инфраструктура, отношения.
- Вовлечённость = увлечённость работой + приверженность + инициативность. Драйверы: практики руководителя (обратная связь, признание, информирование, доверие) + системные факторы (условия труда, эффективность процессов, обучение/карьера).
- Индексы: **eNPS** (рекомендация компании как работодателя; позитив ≥40, негатив <20), **NMS** (рекомендация работать под руководителем). Индекс удовлетворённости = доля «+» минус доля «−», диапазон −100..100, значимая динамика ≥5 п.п.
- **Пульс-опрос:** ≤5 мин, ≤10–15 вопросов, оперативно, не чаще раза в неделю; для отклика на изменения и мониторинга выгорания.
- Орг-индикаторы: физическая среда (здоровье), самореализация, социализация, финансовое благополучие.
- Материалы пачки 1: опрос «Вовлечённость» (2 варианта), опрос «Бизнес-процессы» (4 вопроса), таблица результатов.
