> Блок 5 пришёл двумя пачками, собран целиком. **Внесён в чек-лист v0.6, модуль 8** «Продукт, путь клиента и удовлетворённость». Эта заметка — архив синтеза.

## Повестка блока 5 «Продукт» (4 части) — все ✅
1. Продуктовый подход ✅ · 2. Качество (сотрудник) ✅ · 3. Путь клиента ч.1 ✅ · 4. Путь клиента ч.2 ✅

## Занятия 1–2
- **Продуктовый подход.** Каждый уровень (организация → подразделение → должность) создаёт продукт для клиента; десятки внутренних собираются в 1–2 внешних. Качество (ГОСТ ИСО 9000) = соответствие характеристик требованиям. 12 вопросов; логика «продукт → ожидания → совпало → превзошёл → подтверждено». Метрики CSI, NPS, WOW. Продукт должности.
- **Качество через сотрудника.** Внутренний клиент; вовлечённость = увлечённость + приверженность + инициативность; eNPS (позитив ≥40), NMS, пульс-опрос (≤5 мин). Опросники вовлечённости и бизнес-процессов.

## Занятие 3 — путь клиента ч.1 (CJM)
- Пять этапов жизненного цикла: узнал → купил → доволен эксплуатацией + кросс-продажи → утилизация и почему остался → апостол (виральность).
- Карта: этапы (мотивация/поиск/оценка/оплата/получение/эксплуатация/кросс/утилизация/новая покупка) × действия / чувства (😀🙂☹️) / опыт / ожидания. По каждому продукту — свой путь; проверка опросом 3–4 клиентов. Шаблон — xlsx.
- Факторы восприятия: вижу/слышу/обоняю/осязаю/вкус → чувствую → понимаю.

## Занятие 4 — путь клиента ч.2 (WOW / экономика впечатлений)
- Бизнес продаёт сырьё → товары → услуги → впечатления. Продукт → впечатление (wow) → трансформация клиента (чего хочет → трансформирующее впечатление → сопровождение до прочности).
- Гормоны счастья (дофамин/окситоцин/серотонин/эндорфин); 4 типа впечатлений (развлечение/эстетика/обучение/уход от реальности).
- Проектировать wow на каждом этапе «разумно и достаточно»; за работающие впечатления брать доп.плату. Шаблон — xlsx (этап | изменения для wow | ответственные | затраты | срок).

## Привязка к MainExperts (внесено в модуль 8 чек-листа)
Продукт = отчёт + консультация, клиент = родитель. CJM уже есть в `docs/04`. WOW = ценностное предложение «переход состояния» (тревога→управляемость) + механика скрининга «увидел со стороны» — **держится на невалидированной гипотезе** (помечено риском). Виральность = рефералы по конверсии. Вовлечённость сотрудника — «при масштабе» (команда из пяти).
