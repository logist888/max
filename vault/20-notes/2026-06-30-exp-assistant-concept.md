Рабочее название — EXP (Main EXP). Идея: чат — основной интерфейс взаимодействия с
платформой (по аналогии с тем, как пользователи уже сейчас решают бытовые задачи через
переписку с ChatGPT/другими ИИ — приведён пример пользователя, нашедшего репетитора и
курсы полностью через чат с нейросетью). Внутри чата динамически формируются UI-блоки
(карточки профориентации, кнопка оплаты, форма загрузки документов) — не отдельные
страницы, а элементы, всплывающие прямо в переписке.

Функция ассистента — не просто отвечать, а **вести** пользователя («я твой агент по
твоему развитию, для начала — пройди скрининг»), подсказывать следующий шаг, показывать
короткие выжимки после каждого пройденного модуля («вот что показал скрининг», «вот
короткая выжимка после профориентации»).

**Решение команды:** на первом этапе — это дополнительный ассистент, не ядро системы.
Явно проговорено: «если весь упор сделаем на него, мы его сейчас не потянем» — обучение
ассистента до состояния «ядра платформы» признано отдельной большой задачей, не для
текущего этапа. Начать можно с простого варианта: набор из ~10 стандартизированных
опций взаимодействия (пройти скрининг → пройти профориентацию → и т.д.), подтягивающихся
по мере заполнения профиля.

**Статус:** видение/гипотеза продукта, техническая реализация не начата.
