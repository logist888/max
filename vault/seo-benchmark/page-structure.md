# Структура страниц: Авиасейлс и Booking.com (12.11.2026)

Метод: загружена HTML-разметка по одному образцу каждого типа страницы, разобраны блоки, JSON-LD, интерактивные «острова» (Astro) и состав элементов. Образцы: aviasales.ru и booking.com (локаль ru). Динамика определялась сравнением двух загрузок одной страницы с интервалом около минуты плюс анализом содержимого блока. Это проверка на одном образце, не на выборке.

Не вошло: Skyscanner (капча), страницы отелей Booking.com (проверка браузера, код 202), весь пользовательский поток поиска и брони.

## 1. Авиасейлс: общий каркас (одинаков у всех типов)

Технология: Astro (разметка собирается на сервере, интерактивные части подгружаются «островами» с указанием момента загрузки). Главное для SEO: текст блоков, цены и ссылки есть в исходном HTML, робот видит их без исполнения скриптов.

| Элемент | Состав | Статика / динамика |
|---|---|---|
| Шапка | Избранное, Профиль, Поддержка; форма поиска билетов (остров `AviaFormContainer`, поля город отправления, город прибытия, даты) | Шапка статична; форма интерактивна, начальные значения подставлены под страницу |
| Заголовок H1 | «Авиабилеты из X в Y» | Шаблон + сущности, статично |
| Хлебные крошки | BreadcrumbList (микроразметка) | Статично |
| Подвал | Продукты (экскурсии, отели), партнёры, документы | Статично |
| Мета | title с ценой («…от 1 694 ₽»), description с ценой, canonical, 17 hreflang, Open Graph | title и description динамические (цена); остальное статично |
| Микроразметка | Organization, WebSite, WebPage, BreadcrumbList, Product (цена), FAQPage; по типу страницы: City, Country, Airport, Airline, Flight | Product и FAQ зависят от данных |
| Прочее | Островы `LinksInModal` (6 шт.), `Web2AppContainer` (переход в приложение) | Интерактив |

## 2. Авиасейлс: блоки по типам страниц

Условные обозначения: С — статичный (шаблон/справочник), Д — динамический (цены, расписания, статистика), И — интерактивный элемент.

### 2.1 Маршрут «город → город» (`/routes/mow/led`): 73 533 URL

| Блок (id) | Содержимое | Тип | Элементы |
|---|---|---|---|
| general_info | Время в пути, расстояние, минимальная и средняя цена, рейсов в неделю, самый ранний и поздний рейс | Д (цены, число рейсов); С (расстояние) | Плитки показателей |
| cheap_tickets | Цены, найденные за 48 часов; вкладки «В одну сторону / Туда-обратно» | Д + И | Переключатель вкладок, карусель карточек билета (цена, дата, время, длительность, прямой/пересадка), кнопка «Выбрать даты» |
| direct_flights | Расписание прямых рейсов: авиакомпания, дни недели, цена «от» | Д | Список, кнопка «Показать ещё» |
| prices_dynamic | Динамика цен за год и за 60 дней | Д + И (остров `PricesDynamicContainer`) | График по месяцам, переключатель периода |
| travel_restrictions | Ограничения на въезд | Д + И (остров `TravelRestrictionsContainer`) | Загружается клиентом |
| airlines | Авиакомпании маршрута | Д (состав меняется) | Ссылки на страницы авиакомпаний |
| airports | Аэропорты города отправления и прибытия | С | Ссылки на страницы аэропортов |
| link_buttons | Обратный маршрут, «Авиабилеты в Y» | С | Ссылки-кнопки |
| qa | Вопросы и ответы (время в пути, расстояние и др.) | Шаблон + данные (Д) | Список вопросов; дублируется в FAQPage |
| psgr | «Полезное от ПСЖР»: статьи журнала по городу | Д (свежие публикации) | Карусель из 25 карточек с изображением, рубрикой и датой |
| popular_directions | Другие перелёты: ссылки на соседние маршруты с ценой | Д (цены) | 97 ссылок, 11 кнопок |

### 2.2 Страна (`/countries/abhazia`): 221 URL

general_info (часовой пояс, валюта; С) → to_cities (города страны; С, карусель) → cheap_tickets (карточки билетов; Д) → direct_flights (откуда летят, дни, цена; Д) → distance (расстояние и время из городов; С + цена Д) → airlines (С) → qa (Д) → other_flights (перелинковка, цены; Д).

### 2.3 Город (`/cities/abakan-aba`): 981 URL

general_info (страна, код IATA, число аэропортов, часовой пояс; С) → cheap_tickets (вкладки «Из России / Другие страны»; Д + И) → direct_flights (вкладки по городам вылета; Д + И) → prices_dynamic (4 острова по городам вылета; Д + И) → карта (остров `MapComponent`; И) → airports (С) → airlines (Д) → cities_nearby (С) → qa (Д) → other_flights (Д).

### 2.4 Аэропорт (`/airports/abakan`): 1 507 URL

schedule (онлайн-табло на текущую дату; Д, самый живой блок, есть iframe) → airport_information (адрес, телефон, сайт; С) → nearby_airports (расстояния; С) → airlines (С, 83 ссылки).

### 2.5 Авиакомпания (`/airlines/...`): 326 URL

airline_information (страна, код IATA, сайт; С) → direct_flights (вкладки «Заграницу / Внутренние», маршруты с ценами; Д + И) → airline_cities (С) → qa (Д) → other_airlines (С) → popular_directions (Д).

### 2.6 Рейс (`/flights/a46215-mrv-ayt`): 950 URL

flight_information (номер рейса, авиакомпания, время вылета и прилёта, длительность; Д) → schedule (даты, тип самолёта; Д) → statistics (доли «вовремя / задержка / отмена»; Д) → qa (Д) → other_flights (Д).

### 2.7 Отели, экскурсии, справка

Отдельная система (другой шаблон, без Astro, состояние в `window.__`).
- Отель (47 492 URL): микроразметка Hotel/LocalBusiness, цены, фото, отзывы, форма брони. Основная часть содержимого грузится данными, в статичной разметке мало ссылок (8).
- Экскурсии (4 406 URL): ItemList, 98 изображений, чипы фильтров, карточки с ценами.
- FAQ (44 URL): статья без микроразметки, контактная форма. Статичен.

## 3. Booking.com: структура (локаль ru)

Технология: React (мета через react-helmet), единый «каркас» с микрофронтендом шапки. Микроразметки в исследованных страницах нет, при этом `robots` разрешает индексацию, canonical и 92 варианта hreflang.

### 3.1 Страна (`/country/rw.ru.html`)

| Блок | Содержимое | Тип |
|---|---|---|
| Шапка | Логотип, выбор валюты и языка, помощь, вход и регистрация | С |
| Хлебные крошки | Главная → Отели → Страна | С |
| Hero | Заголовок «Отели в Руанде», подзаголовок «выбирайте из 1095 отелей» | Д (число отелей) |
| Форма поиска | Направление, даты, гости (`searchbox-layout-wide`) | И |
| Лучшие города страны | Сетка ссылок на города | С |
| Популярные регионы | Сетка ссылок | С |
| Рядом с достопримечательностями | Сетка ссылок | С |
| Лучшие отели | Карточки отелей (32 шт.) с названием, ссылкой, оценкой | Д |
| Подвал | Для партнёров, о компании, юридическое | С |

### 3.2 Город (`/city/mh/majuro.ru.html`)

Хлебные крошки (4 уровня) → hero с формой поиска → «Маджуро — 3 отеля и другие виды жилья» (число Д, кнопка «Показать на карте» И) → «Самые бронируемые отели за последний месяц» (Д) → сетка перелинковки.

### 3.3 Состав индекса по sitemap (robots.txt: 443 sitemap-индекса)

Типы, видимые по названиям файлов: отели (hotel), города (city), страны, районы, регионы, аэропорты, достопримечательности (landmark), пляжи, авиамаршруты «город → город» (`/flights/route/city-to-city/...`), прокат авто, `attractions`, `themed-*` (тематические подборки «отели Hilton в городе», «апартаменты», «семейный отдых» и т. п.), редакторские статьи, отзывы. Всего 27 751 дочерних sitemap, 44 локали, на локаль ru 744 файла. В обследованных образцах файл содержит около 49 990 URL (страны: 231, аэропорты: 3 033). Верхняя оценка: порядка 1,4 млрд URL во всех локалях, около 37 млн на локаль ru. Это граница сверху, а не факт: заполнение каждого файла не проверялось.

## 4. Выводы для портала MainExperts (вывод, а не факт)

1. Оба сервиса строят SEO на справочных сущностях со статичной основой (страна, город, аэропорт, регион) и живой «витриной» (цены, табло, число отелей). Результаты поиска и бронь закрыты.
2. Типовой набор блоков на странице сущности: краткие показатели → витрина предложений → график динамики → перелинковка на соседние сущности → вопросы и ответы с FAQPage → материалы журнала → навигация. Вопросы и ответы заполняются шаблоном из данных, поэтому уникальность текста низкая.
3. Перелинковка занимает основную массу ссылок страницы (на узловой странице «Москва» 325 ссылок, на рядовой маршрутной около 176), то есть именно она делает индекс связным.
4. Аналоги для вашей модели: страна, город, вуз, программа, профессия. Как у Авиасейлса, живую часть (цены, даты приёма, рейтинг) можно держать динамической, а модули программ оставить закрытыми.

## 5. Ограничения

- Один образец на тип страницы, один момент времени.
- Динамичность определена по двум загрузкам с интервалом около минуты; блок, который не изменился за минуту, мог бы измениться за сутки. Блоки «DIFF» частично отличались и из-за служебных атрибутов разметки.
- «Тип» (С/Д) отнесён по содержанию блока, это экспертное отнесение, а не измерение.
- Реальное число проиндексированных страниц в поисковиках не измерялось.
