# Воспроизведение MainExperts CJM v4.0

Выгрузка сохраняет 503 стикера из исходного CJM v3 и 43 исходные связи детализации. Первичные состояния J описаны в `config/cjm-scenarios.yaml`. Канонические 327 задач хранятся в `config/tasks.tsv`. Проектные связки оплат P, продуктов R и CTA C берутся из общих справочников. Поисковая сводка читается из `data/country_service.csv` и `data/country_cluster.csv`. Эти таблицы производит `report_data.py` после классификации.

## Сборка

Подготовьте отдельный экземпляр оригинального генератора из [репозитория MainExperts](https://github.com/logist888/max/tree/14816a72b5a30579cf46a47084e6b0739cb2a36a/.claude/skills/cjm-map). Установите Python 3, PyYAML и fontTools, для PDF — WeasyPrint 68.1 с Pango и набором шрифтов Noto Sans с нужными письменностями.

```bash
python -m pip install PyYAML==6.0.3 fonttools==4.61.1 weasyprint==68.1
CJM_SKILL=/absolute/path/to/max/.claude/skills/cjm-map
python "$CJM_SKILL/scripts/selfcheck.py"
python pipeline/build_cjm_v4.py --skill "$CJM_SKILL"
python "$CJM_SKILL/scripts/cjm_map/build.py" cjm/journey-v4.yaml --check
```

Используйте ревизию генератора `14816a72b5a30579cf46a47084e6b0739cb2a36a`. Опция `--skip-pdf` оставляет все остальные форматы. Параметр `--data` указывает папку со сводкой, `--out` — каталог публикации. При отсутствии сводки статусы помечаются как отсутствие входных сведений.

Оригинальный генератор строит шесть векторных карт. HTML объединяет текстовые версии этих карт с таблицами стадий, услуг, региональных сценариев и задач. PDF переносит обзорную карту и детальные таблицы на листы A4. Использован WeasyPrint, поскольку доступный исполняемый файл Chromium не запускался, а загрузка браузера возвращала 403. Исходная геометрия SVG при печати сохранена, видимая часть обрезана по областям переходов и задач.
