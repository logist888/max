# MainExperts · CJM и коммерческий спрос v4.0

Ветка содержит воспроизводимый конвейер, схему CJM, справочники и агрегированную проверку разметки. Базовый коммит генератора: 14816a72b5a30579cf46a47084e6b0739cb2a36a.

Запуск описан в [инструкции](docs/08-pipeline.md). Для запуска на исходном корпусе нужен собственный доступ к выгрузкам. Перечень Drive-папок, примеры исходных фраз, показатели отдельных запросов, подложка CJM v3 и таблицы с измерениями передаются отдельно в закрытом комплекте.

Для повторного прогона классификатора извлеките `pipeline/config/cluster_rules.tsv` из закрытого комплекта v4.0 в одноимённый путь этой ветки. Схема и каталог кластеров доступны здесь. Готовые результаты открываются отдельно, по инструкции для Parquet.

Контрольные результаты доступны в coverage.json и pipeline/validation. Исследование не подтверждает собственные продажи, стоимость привлечения или прибыльность.
