# MainExperts v4.0. Словарь кодов

Справочник обозначений итоговых материалов v4.0 от 26 ноября 2026 года.

В Excel есть все 3 808 наблюдённых подкластеров L5 отдельными строками. В печатной версии для L5 приведены структура и пример. Идентификаторы отдельных запросов  файлов и строк служат ключами исходных реестров.

## Как читать обозначения

Буквы задают тип сущности, номер указывает запись в её справочнике.

| Код | Расшифровка | Как читать |
|---|---|---|
| D1 | Информационный спрос | Формулировка показывает потребность в справке, правиле или объяснении. |
| D2 | Поиск инструмента или персонального результата | Например, калькулятор, проверка или оценка. Такой результат может быть бесплатным. |
| R03 | Проверенный короткий список программ | Цифровой продукт. Основная гипотеза услуги P06, персональный подбор образования. |
| E10 | Диагностическая проба | Элемент интерфейса, который возвращает базовую оценку с объяснением. |
| C-P01-F | Бесплатный вход по услуге P01 | Элемент E10 и действие «Пройти короткую пробу». |
| K001-I07:AE:en | Пример составного L5 | K001 — диагностика. I07 — поиск инструмента. AE — ОАЭ. en — английский. |

## Указатель по кодам

Одинаковый номер в кодах разных семейств не означает связь. Например, R03, P03, Q03 и E03 имеют самостоятельные значения.

| Формат | Что обозначает | Где смотреть |
|---|---|---|
| D0–D6 | Уровень доказательности спроса | Лист D |
| G01–G07 | Цель пользователя в поле GOAL_ID | Лист L и цели |
| G01–G22 | Пробел исследования в поле GAP_ID | Лист Пробелы и границы |
| L0–L6 | Уровень иерархии онтологии | Лист L и цели |
| Q01–Q22 / Qxx.nn[a-z] | Ветвь / конкретная задача пользователя | Листы Q и Задачи Q |
| J01–J09 | Состояние пользователя на карте CJM | Лист Карта CJM |
| I01–I15 | Какой результат пользователь пытается найти | Лист I |
| K001–K141 | Базовое семейство поисковой потребности | Лист K |
| Knnn-Ixx | Семейство K и поисковое намерение I | Лист Кластеры L4 |
| Knnn-Ixx:рынок:язык | Конкретный подкластер поискового рынка и языка | Лист Подкластеры L5 |
| P01–P26 | Гипотеза услуги или точки оплаты | Лист P |
| R01–R14 | Продукт, предложенный к проверке | Лист R |
| E01–E28 | Функциональный элемент интерфейса | Лист E |
| C-Pnn-X / C-neutral-* | Путь от входа до следующего действия | Листы Сценарии и CTA |
| B01–B13 | Правило разграничения похожих задач | Лист Пробелы и границы |
| GS01–GS48 / MX01–MX25 | Источники для восполнения пробелов / внешние аналоги | Лист Источники |
| GB / UK / en / und / ZZ-RU | Рынок, страна обучения, язык или недостающая география | Листы Рынки и Языки и статусы |
| ME_* / PARTNER_* / EXTERNAL_* | Тип и получатель платежа | Лист Оплата |
| CPC / KD / QUERY_ID / CTA | Метрики, сокращения и имена полей | Листы Термины и Поля |

## D. Уровни доказательности

D0–D6 показывают качество подтверждения. В исследовательской базе v4.0 встречаются D0–D3.

| Код | Расшифровка | Как понимать |
|---|---|---|
| D0 | Осмысленная гипотеза с тестом и объяснением платной ценности | Сама гипотеза сохраняется при отсутствии подтверждения. |
| D1 | Наблюдаемая информационная формулировка | Подтверждает потребность в ответе в обследованном корпусе. |
| D2 | Наблюдаемый поиск инструмента или персонального результата | Пользователь может искать бесплатное решение. |
| D3 | Коммерческий характер исходной строки подтверждён её смыслом | Отдельно проверяются объект покупки, исполнитель и получатель платежа. |
| D4 | Наблюдаемый спрос на конкретную платную образовательную услугу | Сохраняются точная формулировка, исходный источник, рынок и основание соответствия. Доказательство привязано к услуге, а цена MainExperts требует своего опыта. |
| D5 | Проверенная покупка собственного продукта | Требуется факт оплаты MainExperts с каналом, продуктом и когортой. |
| D6 | Доказанная окупаемость и масштабируемость на собственных сделках | Нужны данные оплаты, исполнения, возвратов, цены трафика и повторяемая экономика при росте. |

## I. Поисковые намерения

Какое действие или ответ ищет пользователь. Уровень доказательности D хранится отдельно.

| Код | Намерение | Когда применять |
|---|---|---|
| I01 | Узнать и разобраться | Достаточно ответа, справки, действующего правила или определения. |
| I02 | Найти варианты | Требуется множество или доступный вариант по критериям. |
| I03 | Сравнить варианты | Нужны сопоставляемые альтернативы на общей основе. |
| I04 | Проверить соответствие | Есть объект и критерий, нужен проверяемый ответ. |
| I05 | Получить персональную оценку | Нужна интерпретация индивидуального профиля или ситуации. |
| I06 | Выполнить расчёт | Ожидается численное значение с параметрами и единицей. |
| I07 | Получить инструмент | Ищут калькулятор, шаблон, тест, трекер или интерактивную форму. |
| I08 | Получить документ или готовый результат | Ищут выдачу определённого результата. На кого возложено действие, определяется отдельно. |
| I09 | Найти специалиста | Ищут исполнителя по определённой профессиональной задаче. |
| I10 | Узнать стоимость услуги | Объект цены — коммерческая помощь или платный результат. Стоимость самой учёбы кодируется по задаче о тарифе и бюджете. |
| I11 | Заказать или оплатить | Есть явное действие покупки. Получатель денег и объект покупки устанавливаются отдельно. |
| I12 | Найти конкретного поставщика | Бренд, сайт или личный кабинет идентифицируются. Сам факт имени не отражает покупку. |
| I13 | Отслеживать изменения | Ожидается повторная сверка состояния или сигнал об изменении. |
| I14 | Продолжить ранее начатое действие | Существует уже начатое дело. По запросу понятно, что надо вернуться к нему. |
| I15 | Выполнить действие у образовательной или официальной стороны | Регистрация на экзамен, передача заявки, запись на событие или перечисление внешнего сбора. У действия указан получатель. |

## L и G. Уровни и цели

Здесь G относится к полю GOAL_ID. Коды G из реестра пробелов приведены отдельно.

| Код | Значение | Результат или связи |
|---|---|---|
| L0 · цель | Состояние образовательного маршрута, которого хочет достичь человек | G01–G07. Один Q-лист может поддерживать несколько целей. При однозначной формулировке записывается основная цель. |
| L1 · класс задач | Основная предметная ветвь работы | Исходные Q01–Q22. Предметная ветвь может возникнуть в нескольких состояниях CJM. |
| L2 · конечная задача | Операция над носителем результата | Оригинальный TASK_ID, например Q02.04a. При частичной определённости сохраняется ветвь и причина, лист остаётся неизвестен. |
| L3 · ожидаемый результат | Проверяемый ответ или новый артефакт | Контракт листа указывает тип результата и основной носитель. Экземпляр ответа имеет источники, применимость и состояние. |
| L4 · кластер намерения | Одно действие поиска ради одного типа ответа | Стабильный CLUSTER_ID. Разметка учитывает намерение и объект. Кластер может иметь подтверждённый лист, кандидатов или только ветвь, если данных меньше. |
| L5 · подкластер | Реализация того же поискового контракта на конкретном языке и поисковом рынке | SUBCLUSTER_ID. Назначение обучения записывается отдельно, а отдельная процедура может менять смысл кластера. Не подтверждённый рынок/язык сохраняет неизвестность. |
| L6 · исходная формулировка | Запись запроса в источнике | QUERY_ID и координата исходного наблюдения. Нормализация не заменяет оригинал. |
| G01 | Определить будущий образовательный или профессиональный маршрут | Известен проверяемый ближайший шаг и запасной вариант Ветви Q01, Q02, Q19, Q21, Q22. |
| G02 | Найти пригодное образовательное предложение | Есть список реализаций или объектов, соответствующих ограничениям Ветви Q02, Q03, Q04, Q05, Q06, Q07, Q08, Q14, Q18, Q21. |
| G03 | Проверить осуществимость конкретного варианта | Есть отдельно проверенные статус, доступ, сроки, бюджет и ограничения Ветви Q05, Q07, Q08, Q09, Q10, Q13, Q14, Q15, Q16, Q18. |
| G04 | Получить результат оценивания или подготовиться к нему | Известен, получен или улучшен конкретный измеряемый результат Ветви Q09, Q10, Q17, Q20, Q21. |
| G05 | Получить или сохранить право учиться по выбранному пути | Подготовлено дело или получен отдельно подтверждённый официальный переход Ветви Q05, Q09, Q11, Q12, Q13, Q16, Q17, Q21, Q22. |
| G06 | Обеспечить оплату, участие и условия жизни | Известно покрытие, подтверждён порядок финансирования или организованы условия Ветви Q12, Q14, Q15, Q16, Q17, Q18, Q21. |
| G07 | Завершить, изменить или применить образовательный результат | Принято самостоятельное решение о продолжении, зачёте, признании или выходе к профессии Ветви Q08, Q10, Q13, Q17, Q19, Q20, Q22. |
