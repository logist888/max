# Интерактивное исследование MainExperts P01

HTML связывает запросы, проекты, наблюдавшиеся маршруты и снимки экранов. Открывайте готовый файл локально в браузере. Поиск, фильтры и галерея работают без подключения к интернету. Ссылки на источники открывают внешние сайты.

## Сборка

Распакуйте закрытый пакет доказательств `mainexperts-p01-evidence.zip`. Передайте каталог с папками `data/` и `screenshots/` и путь к итоговому файлу.

```bash
python3 build.py /path/to/evidence /path/to/mainexperts-p01-interactive.html
```

Сборщик использует стандартную библиотеку Python и встраивает данные и оригинальные JPEG в итоговый файл. Храните собранный HTML с теми же ограничениями доступа, что и исходный пакет доказательств.
