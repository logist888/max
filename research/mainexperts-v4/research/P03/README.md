Сборщик открывает исходную базу только для чтения. Воспроизведение требует DuckDB и архива исходного исследования с разрешённым доступом. [Описание конвейера v4](../../docs/08-pipeline.md).

```bash
python study.py /path/to/mainexperts-v4.duckdb /path/to/p03-candidates
python review.py /path/to/p03-candidates/queries_pending.csv /path/to/p03-review.csv
python interactive/build.py /path/to/p03-evidence /path/to/mainexperts-p03-interactive.html
```

HTML показывает диапазон, тип и наличие оценки частотности, сортировку и доказательность D1–D3. Нулевые значения сохраняются отдельно от пропусков. Готовый HTML содержит исходные данные. Распространяйте его в пределах разрешённого доступа к корпусу.
