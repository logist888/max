# MainExperts v4.0. P06 — персональный подбор образования

P06 охватывает поиск по ограничениям, пригодность для конкретного человека и короткий список. Каталог, персональный результат, ценовое предложение, доступное оформление и покупка учитываются отдельно. Рейтинговый поиск и административные действия отделены.

```bash
python study.py /path/to/mainexperts-v4.duckdb /path/to/p06-candidates
python review.py /path/to/p06-candidates/queries_pending.csv /path/to/p06-review.csv
python interactive/build.py /path/to/p06-evidence /path/to/mainexperts-p06-interactive.html
```

HTML содержит поиск и совместимые фильтры типа оценки, наличия, диапазона, сортировки и уровня D1–D3. Сборщик упаковывает данные в gzip для автономного просмотра в современных браузерах. Исходные запросы и скриншоты в закрытом комплекте. [Описание восстановления базы](../../docs/08-pipeline.md).
