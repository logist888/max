В поисковых данных подтверждён D1. Ценовые предложения поставщиков рассматриваются отдельно от поискового намерения и наблюдавшейся покупки. Для MainExperts рассматривается бесплатная схема системы с переходом к R02 в спорной ситуации допуска.

Скрипт `study.py` использует Python и DuckDB. Для восстановления базы см. [описание конвейера v4](../../docs/08-pipeline.md). Отбор строится на исходных метках, расширенных языковых правилах и повторной проверке кандидатов.

```bash
python study.py /path/to/mainexperts-v4.duckdb /path/to/p02-candidates
python interactive/build.py /path/to/p02-evidence /path/to/mainexperts-p02-interactive.html
```

Готовый HTML и полный набор доказательств содержат исходные поисковые данные. Распространяйте их с учётом разрешений на исходный корпус. Код сборки публикуется отдельно.
