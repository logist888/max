# MainExperts v4.0. P05 — мониторинг наборов и сроков

P05 охватывает дату начала набора, состояние подачи, срок заявления, дополнительные раунды и отслеживание изменений. Даты финансирования и экзаменов, оплата заявки и учебное расписание учитываются отдельно.

Повторный проход использовал восстановленную базу v4.0. Отдельная критическая проверка проверила многоязычные формулировки напоминаний и мониторинга. Вместо подстановки даты из соседней страницы запись хранит первичный URL, год и границы подтверждения.

```bash
python study.py /path/to/mainexperts-v4.duckdb /path/to/p05-candidates
python review.py /path/to/p05-candidates/queries_pending.csv /path/to/p05-review.csv
python interactive/build.py /path/to/p05-evidence /path/to/mainexperts-p05-interactive.html
```

В HTML доступны диапазон оценки, метрика, наличие оценки, сортировки и доказательность D1–D3. Исходные запросы и скриншоты находятся в комплекте доказательств. [Описание восстановления базы](../../docs/08-pipeline.md).
