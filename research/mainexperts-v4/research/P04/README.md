# MainExperts v4.0. P04 — аудит образовательной программы

P04 охватывает идентификацию программы, учебный план, результаты обучения, условия двойного диплома и встроенную практику. Поисковый запрос, фактический публичный ответ, денежное предложение и покупка учитываются как разные свидетельства.

Повторный проход использовал восстановленную базу v4.0 с 245 выгрузками и 14 исходными папками. Подтверждены информационные запросы. Публичный платный аналог показывает, какой результат можно предложить пользователю, уже выбравшему программы.

```bash
python study.py /path/to/mainexperts-v4.duckdb /path/to/p04-candidates
python review.py /path/to/p04-candidates/queries_pending.csv /path/to/p04-review.csv
python interactive/build.py /path/to/p04-evidence /path/to/mainexperts-p04-interactive.html
```

В HTML доступны фильтры частотности, метрики, наличия оценки, рынка, языка, кластера и доказательности. Исходные строки, скриншоты и готовый HTML хранятся в закрытом комплекте. [Описание восстановления базы](../../docs/08-pipeline.md).
