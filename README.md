# MainExperts — система обработки файлов и сборки отчётов

Это рабочее место для приёма длинных материалов (20–50 стр.) по проекту MainExperts,
их хранения в связной базе знаний (по образцу Obsidian) и сборки отчётов.

## С чего начать в новой сессии
Вставь содержимое `BOOTSTRAP.md` первым сообщением — или вызови скилл `boot`.
Загрузчик прочитает протокол, память и карту хранилища, поставит зависимости и
сверится с Google Drive.

## Карта
- `CLAUDE.md` — протокол поведения (грузится автоматически каждой сессией).
- `SYSTEM.md` — устройство: контуры хранения, модель заметки, хранение и загрузка.
- `BOOTSTRAP.md` — промпт загрузки системы.
- `docs/` — **канон знаний** (кураторский): `01-strategy` … `21-lk-pisma-voronki`;
  `docs/00-mainexperts-i-proforientaciya.md` — единый ввод: что за компания и что за продукт;
  `docs/boards/` — модуль управленческих бордов (MMS Том I+II); `docs/bpmn/` — схемы
  процессов; `docs/dms/` — система документооборота; `docs/html/` — визуализации
  канона; `docs/prompts/` — рабочие промпты; `docs/private/` — поток-1, вне git.
- `reference/` — оригиналы методологий. `memory/memory.md` — дословный снимок памяти с Drive.
- `vault/` — **рабочие заметки** из новых ингестов: `00-index` (карта, метки),
  `10-sources`, `20-notes`, `30-entities`, `40-reports`, `_templates`.
- `scripts/` — `extract.py` (файл → текст), `pdf_ru.py` (отчёт → кириллический PDF),
  `setup.sh`, `requirements.txt`.
- `seo-platform/` — проектирование SEO-платформы по выбору образования (Поток 2):
  `00-audit.md` — аудит задачи и базы вузов; `01-model-ia.md` — модель данных
  и информационная архитектура; `02-pseo.md` — Programmatic SEO и индексация;
  `03-search.md` — поиск; `04-product.md` — карточки, фильтры, конверсия, AI;
  `05-tech.md` — стек, база, API, админка; `06-operations.md` — дизайн-система,
  производительность, аналитика, эксплуатация; `07-roadmap.md` — дорожная
  карта запуска; `audit_csv.py`, `audit_json.py`, `inventory.py` —
  воспроизводимые расчёты.
- `.claude/skills/` — `boot`, `ingest`, `report`.
  `setup.sh`, `requirements.txt`; `transcribe/` — расшифровка записей по голосам.
- `transcripts/` — готовые транскрипты встреч (звук и кеш — вне git).
- `.claude/skills/` — `boot`, `ingest`, `report`, `publish`, `transcribe`.
- `.claude/skills/` — `boot`, `ingest`, `report`, `publish`; плюс набор UI/UX Pro Max (`ui-ux-pro-max`, `design`, `design-system`, `ui-styling`, `brand`, `slides`, `banner-design`) — дизайн-интеллект для интерфейсов, установлен через `npx ui-ux-pro-max-cli init --ai claude`, обновление той же командой с `--force`.

## Три рабочих действия
- **transcribe** — расшифровать запись созвона по голосам с таймкодами.
- **ingest** — принять файл и разложить в `vault/`.
- **report** — собрать отчёт из `vault/` и выгрузить PDF в Drive.

Жёсткие правила проекта (два потока раздельно; гипотеза скрининга не валидирована;
переименование тестов; источник+дата+ссылка; обезличивание команды на выходе) —
в `CLAUDE.md`, система держит их на уровне структуры.
