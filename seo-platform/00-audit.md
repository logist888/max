# SEO-платформа по выбору образования — Этап 0: аудит задачи

> Дата: 11.07.2026. Статус: **архитектура не начата** — по главному правилу задания
> проектирование останавливается до ответов на вопросы раздела 6.
> Каждая цифра этого документа воспроизводится скриптом `seo-platform/audit_csv.py`.

Место в проекте: платформа — канал **Потока 2** (воронка самообслуживания):
органический поиск → контент → квиз/скрининг → диагностика. Она целиком опирается
на центральную гипотезу проекта («скрининг оцифровывает страхи родителя →
покупка диагностики»), которая **не валидирована** — это ставка, и все прогнозы
конверсии платформы наследуют этот статус.

## 2. Критические дефекты данных

**Д1 — блокер. Поле `programs` обрезано на лимите экспорта ~30 000 символов.**
162 вуза имеют поле длиной ровно 30 001 символ с оборванным JSON. Заявлено у них
84 102 записи программ, физически в файле 31 567, **потеряно 52 535 (62%)**.
Полный объём базы должен быть ~139 тыс. записей — в файле пригодно 55 тыс.
Пострадали именно флагманы — ядро поискового спроса: МГУ, СПбГУ, ВШЭ,
МГТУ им. Баумана, МИФИ, ИТМО, РУДН, УрФУ, КФУ, СФУ, ЮФУ, Сеченовский, РАНХиГС,
РЭУ им. Плеханова, СПбПУ. Строить страницы программ топ-вузов на этих данных
нельзя. Лечение — пересобрать экспорт без лимита ячейки (см. вопрос A1).

**Д2. Города не нормализованы.** «г. Москва» и «Москва» — разные значения;
53 группы разночтений. Решаемо на импорте, но лучше нормализовать в источнике.

**Д3. Нет связи «филиал → головной вуз».** Поля parentId нет; 577 филиалов
распознаются только по слову «филиал» в названии. Для карточек вузов и
перелинковки связь придётся восстанавливать (частично — из названий, ненадёжно).

**Д4. Расхождение счётчика и списка у неповреждённых.** У 615 из 1642 проверенных
вузов «Направлений подготовки» ≠ числу записей в `programs` (пример: ДОННАСА —
заявлено 131, записей 99). Причина неизвестна: либо счётчик источника считает
иначе, либо парсер терял записи. Требует проверки на стороне парсера.

**Д5. Зарубежные филиалы.** 28 записей с регионом «Территория иностранного
государства» (Ереван, Баку, Астана…) — нужна продуктовая политика: показывать ли
их и где (вне географии РФ).

**Д6. Пропуски стоимости.** 1 246 платных записей (5,1%) с cost=0 —
на карточке показывать «Информация отсутствует», не ноль.

Единственный допустимый внешний справочник без выдумки — официальный перечень
УГСН (группы кодов ОКСО: 44 «Образование», 38 «Экономика и управление»…):
коды в базе есть, названия групп — нормативный документ Минобрнауки.
Подключение любого внешнего источника — только по правилу данных проекта:
источник, дата, ссылка.

## 5. Недопустимые предположения (зафиксированы)

1. Достраивать отсутствующие данные (баллы, рейтинги, описания) — запрещено заданием.
2. Считать обрезанные данные «почти полными» — потеряно 62% у флагманов.
3. Смешивать метрики платформы (Поток 2) с Потоком 1 — правило проекта.
4. Использовать названия BFAS/Big Five и RIASEC в клиентских текстах платформы —
   лицензии нет, только рабочие названия (правило проекта).
5. Обещать прогноз трафика/конверсии как факт — гипотеза скрининга не валидирована.

## 8. Проверка пересборки от 11.07.2026 (JSON) — Д1 закрыт

Файл: `universities_master_1.json`, 30 383 953 байта,
sha256 `a7559645…41a1c6`. Проверка — `seo-platform/audit_json.py`
(вторым аргументом принимает старый CSV для повузовой сверки).

**Итог: обрезка устранена, база пригодна для этапа 1.**

- JSON валиден целиком; 1813 организаций, дублей id нет; массивы вместо
  строк с внутренним JSON — формат корректный.
- Записей программ **100 164** (было пригодных 55 082): все 1642 неповреждённых
  вуза совпали с CSV запись в запись (0 потерь, 0 расхождений), все 162 бывших
  обрезанных восстановлены (187–368 записей на вуз).
- Флагманы правдоподобны: МГУ — 333 записи, **117 уникальных направлений ОКСО**
  по четырём уровням; следов пагинационного потолка нет (значения не
  кластеризуются у одной границы).
- Уникальных ОКСО стало 894 (было видно 836). Платных записей 42 709,
  без стоимости 2 621 (6,1%) — Д6 остаётся, показывать «Информация отсутствует».

Что осталось открытым после пересборки:

- **Д4 уточнён, не закрыт.** Счётчик «Направлений подготовки» совпадает со
  списком у 1027 вузов, расходится в пределах ±5 у 262 и сильно у 515
  (УрФУ: заявлено 1568, в списке 327). Худшие отношения — у педвузов
  (УрГПУ ×6,2), где направления дробятся на профили. Рабочая гипотеза:
  счётчик источника считает образовательные программы/профили, а список —
  конкурсные позиции «направление × уровень × форма × тип мест» (дубли таких
  кортежей с разными местами и ценой в базе есть — это разные конкурсы).
  Проверяется одним сравнением живой страницы источника с выгрузкой на
  стороне парсера (страницы публично доступны, но это SPA — нужен внутренний
  API парсера). До проверки число «направлений подготовки» на карточках
  брать из списка программ, счётчик источника не публиковать.
- **Новое: ординатура и ассистентура-стажировка систематически отсутствуют.**
  В индикаторе уровней ординатура заявлена у 212 вузов, ассистентура у 49,
  но в `programs` таких записей 0; все 9 вузов без программ — чисто
  ординатурные медцентры. Для ЦА платформы (подростки 10–18) это вне ядра,
  но карточки должны показывать «уровень заявлен, программы не выгружены»,
  а не «программ нет».
- В программах присутствуют уровни пилота новой системы ВО — «Базовое высшее
  образование» (2 314) и «Специализированное высшее образование» (654):
  таксономия уровней платформы обязана держать обе системы одновременно.
- Д2 (нормализация городов), Д3 (связь филиал → головной вуз), Д5 (зарубежные
  филиалы) — без изменений, переходят в требования импорта этапа 1.
