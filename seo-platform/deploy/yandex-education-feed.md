# Фид для Яндекса: «Образовательные онлайн-курсы и уроки»

Файл собирается генератором `app/src/feed/yandex-education.ts` (`npm run feed`)
и кладётся в `dist/yandex-education.yml`, то есть на сайте доступен по адресу
`https://vuz-navigator.ru/yandex-education.yml`.

## Прочитать до загрузки

Формат рассчитан на площадки, которые **сами проводят обучение онлайн**.
Дословно из документации Яндекса: «Сайты, предлагающие курсы и другие
образовательные услуги, которые проводятся онлайн»; при загрузке — «выберите
категорию бизнеса Образование, если данные касаются курсов или уроков, которые
проводятся онлайн».

ВУЗ-навигатор — справочник: обучение не проводит, не продаёт и не является
правообладателем программ. Фид собран по решению владельца, и перед отправкой
надо понимать, на что именно соглашаемся.

Фид проходит модерацию: «информация о сайте и предложениях будет проверена
службой контроля качества», «фид может быть отклонен за нарушение правил».
Отклонение — ожидаемый исход, и это не ошибка сборки.

## Вынужденные допущения

| Что | Как в документации | Как у нас |
|---|---|---|
| Тематика | курсы, проводимые онлайн | очное обучение в вузе |
| `price` | «стоимость за весь курс» | минимальная стоимость **за учебный год**: срок обучения источник не публикует. В `description` это сказано прямым текстом |
| `categoryId` | из рубрикатора курсов | в рубрикаторе нет высшего образования. Берём ближайшее по предметной области: «Переподготовка» по отраслям и «Изучение наук». Соответствие приблизительное |
| «Ссылка на контент курса» | внутренняя страница, где идёт обучение | не передаётся: поля нет и выдумывать его нельзя (оно необязательное) |
| «Формат обучения» | 4 значения, все про онлайн | «С преподавателем» — ближайшее; варианта «офлайн» в списке нет |

Что **не** подгонялось: названия, адреса, количество вузов, стоимость и наличие
бюджетных мест берутся из выгрузки как есть.

## Единица предложения

Предложение — это страница сайта, потому что Яндекс требует уникальный `url`:

- страницы направлений `/specialnost/<направление>/`;
- индексируемые связки `/specialnost/<направление>/<город>/`.

Пары «вуз × направление» единицей быть не могут: отдельной страницы у них нет.
Предложения без известной платной стоимости не включаются — иначе `price = 0`
Яндекс прочитает как «обучение бесплатное».

Сейчас в фиде около 5 500 предложений при лимите 30 000, запас есть.

## Перед сборкой задать почту

`email` — обязательное поле, это адрес для обращений по курсам. По умолчанию
подставляется `info@vuz-navigator.ru`, и генератор об этом предупреждает.
Задайте реальный адрес:

```bash
cd seo-platform/app
FEED_EMAIL=you@example.com SITE_URL=https://vuz-navigator.ru npm run feed
```

## Логотип

В `picture` уходит `/favicon.svg`. Яндекс просит квадрат не меньше 100 × 100 в
PNG или SVG — SVG векторный, требование выполняется. Имеющийся `logo.png`
не подходит: он 95 × 69 и не квадратный.

## Как загрузить

1. Яндекс Вебмастер → подтвердить права на `vuz-navigator.ru`.
2. **Услуги и предложения в поиске** → **Фиды и ошибки** → **Загрузить фид**.
3. Категория бизнеса — **Образование**, регион — **Россия**.
4. В поле «Ссылка на файл с предложениями» указать
   `https://vuz-navigator.ru/yandex-education.yml`.

Фид перечитывается Яндексом по расписанию, поэтому при каждом обновлении сайта
его достаточно пересобрать и выложить по тому же адресу.

## Пересборка

```bash
cd seo-platform/app
npm run site      # данные + граф + сайт + фид
# или только фид, если dist уже собран:
FEED_EMAIL=... SITE_URL=https://vuz-navigator.ru npm run feed
```
