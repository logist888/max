# Фотографии вузов

Снимок здания на странице вуза и превью рядом с названием во всех списках.
Где снимка нет, в списке стоит заглушка — плашка со знаком из логотипа.
Её рисуют стили, отдельного файла нет. Как только снимок появляется в карте
соответствий, заглушка при следующей сборке сама сменяется на фото.

Состояние на 26.11.2026: снимок есть у 684 вузов из 1 236 головных. Из них
412 с Викисклада и 272 с Vuzopedia.

## Как пополнять

Порядок важен: сначала Викисклад, потом Vuzopedia. У снимка с Викисклада
есть автор и лицензия, поэтому он лучше, и скрипты не трогают вуз, у
которого снимок уже стоит.

```bash
cd seo-platform
python3 scripts/photos/commons.py               # Викисклад: найти и скачать
python3 scripts/photos/vuzopedia.py crawl       # Vuzopedia: обойти каталог (~5 мин)
python3 scripts/photos/vuzopedia.py match       # подобрать, отсеять мусор
#   → посмотреть data/photos/review/sheet.jpg
python3 scripts/photos/vuzopedia.py install --reject 3,7   # номера плохих плиток
python3 scripts/photos/make_thumbs.py           # превью для списков
cd app && SITE_URL=https://vuz-navigator.ru npm run build
```

Перед запуском нужна собранная база сайта (`app/build/org-cards.json`):
скрипты берут вузы оттуда.

## Два источника — разные правила

| | Викисклад | Vuzopedia |
|---|---|---|
| Поле `src` в карте | `commons` | `vuzopedia` |
| Подпись под снимком | выключена (см. ниже) | нет |
| `license`, `acquireLicensePage` в schema.org | выключены (см. ниже) | нет |
| Привязка к вузу | домен официального сайта через Викиданные | город + аббревиатура или полное название |
| Размер | до 800 px | 520×390 (кроп по центру из 520×700, крупнее у них нет) |

**Источник снимков на сайте не показывается** — решение владельца проекта от
26.11.2026, юридическая сторона на нём. Ни подписи «Фото: Викисклад, автор,
лицензия», ни полей прав в разметке. Переключатель — `SHOW_PHOTO_CREDITS` в
`app/src/lib/photos.ts`. Для справки при пересмотре: у 345 из 412 снимков с
Викисклада лицензия CC BY / CC BY-SA / GFDL / FAL, и её условие — указать
автора и лицензию; у 67 (Public domain, CC0) такого условия нет. Авторы и
лицензии по-прежнему собираются в карту соответствий, на сайт она не
попадает, так что подписи возвращаются одной правкой.

**Vuzopedia** — решение владельца проекта от 26.11.2026, юридическая сторона
на нём. Ссылки на официальный сайт вуза на карточках Vuzopedia нет, поэтому
вуз сопоставляется по правилу владельца: **совпадает город и (аббревиатура
или полное название)**. Подробности и уточнения правила — в начале
`vuzopedia.py`. На ручной разметке правило не дало ни одной чужой пары.

## Что отсеивается автоматически

- **Заглушка Vuzopedia** — синяя иллюстрация со зданием и студентами. У
  каждой карточки она перезалита под своим именем, поэтому её ищут по
  содержимому: отпечаток лежит в `data/photos/vuzopedia-stub.sig`. Самой
  картинки в репозитории нет, это чужой файл.
- **Логотип вместо фото** — когда у карточки нет снимка, в каталоге стоит
  логотип 148×148.
- **Логотипы и гербы на Викискладе** — по имени файла. Заглавная картинка
  статьи в Википедии чаще всего логотип из карточки.

## Что отсеивает только человек

Рекламные баннеры, текстовые плашки, абстрактная графика, звёздное небо у
института солнечно-земной физики. На это смотрят глазами на листе
`data/photos/review/sheet.jpg`. Отклонённые попадают в
`data/photos/vuzopedia-rejected.json` вместе с адресом снимка: если
Vuzopedia заменит картинку, пара снова придёт на просмотр.

## Файлы

- `data/photos/vuz-photos.json` — карта соответствий, описание полей в `common.py`.
- `data/photos/vuzopedia-cards.json` — последний обход каталога Vuzopedia.
- `data/photos/vuzopedia-rejected.json` — отклонённые при просмотре.
- `data/photos/vuzopedia-stub.sig` — отпечаток заглушки Vuzopedia.
- `app/public/photos/<slug>.webp`, `-360.webp`, `-thumb.webp` — сами снимки.

## Грабли, на которые уже наступили

- **Ширина превью Викисклада.** Только ступени из списка в `commons.py`.
  Ширина 640 давала 429 почти на каждом файле.
- **Город сравнивать целиком.** По первым пяти буквам Владивосток совпадает
  с Владимиром, а «омск» входит в «Томск».
- **Совпадение только по названию без проверки — не привязка.** На
  Викиданных из 38 таких пар ссылкой на сайт подтвердились 7.
- **Проверка лицензии.** У CC BY и CC BY-SA без автора снимок не ставится.
