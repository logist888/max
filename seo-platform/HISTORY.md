## Инварианты, которые соблюдались

- **Не выдумывать:** нет данных → «Информация отсутствует»; каждый премиум-факт с источником/датой/атрибуцией.
- **Честность фильтров:** фасет строится только на реальных данных элемента; на страницах направления/комбо — по офферам этого ОКСО, не по агрегатам вуза.
- **SEO не ломается:** URL-состояние фильтров через `replaceState`; canonical режет query; `robots Disallow /*?`; sitemap чист.
- **Прогрессивное улучшение:** контент виден без JS и при `prefers-reduced-motion`; движение включается опционально.
